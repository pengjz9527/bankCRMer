## 关键UI设计模式总结

### 通用页面结构

```
┌──────────────────────────────────┐
│         顶部标题栏 / 搜索栏         │  ← 搜索框 + 筛选条件行
├──────────────────────────────────┤
│                                  │
│         核心信息展示区             │  ← 四宫格 / 关键指标卡片
│                                  │
├──────────────────────────────────┤
│                                  │
│         扩展信息区                │  ← 折叠展开 / 分组卡片
│   （基础信息 / 交易规则 /         │
│     历史业绩 / 持仓等）           │
│                                  │
├──────────────────────────────────┤
│         LLM生成分析区             │  ← 一句话总结 / 对比结论
├──────────────────────────────────┤
│         底部操作区 / 导航          │  ← 按钮 / Tab导航
└──────────────────────────────────┘
```

### 通用卡片模式

```
┌─────────────────────────┐
│  主标题（如：产品名称）     │
│  副标题（如：产品代码）     │
├─────────────────────────┤
│  ┌────┬────┬────┬────┐ │
│  │左上│右上│    │    │ │  ← 四宫格核心指标
│  │    │    │    │    │ │
│  ├────┼────┼────┼────┤ │
│  │左下│右下│    │    │ │
│  └────┴────┴────┴────┘ │
├─────────────────────────┤
│  标签行（类型/风险/状态）  │
├─────────────────────────┤
│  操作按钮区域             │
└─────────────────────────┘
```

### 对话交互模式

```
┌──────────────────────────────────┐
│         会话标题栏                 │
├──────────────────────────────────┤
│                                  │
│   [用户消息气泡]                   │  ← 自然语言或卡片搜索
│                                  │
```

# AI营销展业助手（易会办）—— 面谈中交互流程设计

> 目标：定义面谈开始到面谈结束的完整交互流程，包括每一步的跳转逻辑和所需页面。
>
> ⚠️ **设计约束**：作战包源于商机。商机生成作战包时同步创建商机待办。面谈准备不是独立待办，是"拜访客户"商机待办的组成部分。

---

## 一、所需交互页面清单

| 编号 | 页面名称 | 用途 | 是否主界面 |
|:---:|------|------|:---:|
| P1 | 作战包首页 | 面谈前的最后确认，点击"开始面谈"的入口 | — |
| **P2** | **面谈主界面** | **面谈中的核心操作界面，承载剧本执行+偏离应对+产品展示** | ✅ 主 |
| P3 | 偏离详情卡片 | 点选偏离分支后展开的完整响应内容（话术+策略+产品） | 子页面 |
| P4 | 展示模式页 | 客户可见的产品展示界面（私密→展示切换后的状态） | 子页面 |
| P5 | 线索切换面板 | 中途跳转到不同线索/话题的选择器 | 浮层 |
| P6 | 快速记录浮层 | 不离开主界面的轻量笔记录入 | 浮层 |
| P7 | 面谈结束页 | 面谈总结、偏离补充、创建跟进任务的收尾界面 | 终态 |
| P8 | 兜底搜索界面 | 偏离都不匹配时的自由搜索入口 | 子页面 |
| P9 | 客户确认要点 | 给客户看的交流要点+后续待办（可选，展示模式风格） | 子页面 |

## 三、逐步交互跳转逻辑

### Step 0：作战包首页 → 开始面谈

```
P1 作战包首页
│
├── 展示内容：完整的访前作战包（客户速览+线索清单+议程+风险提示）
│
├── 操作选项：
│   ├── [开始面谈] → 进入 P2 面谈主界面，默认展示第一条线索
│   ├── [编辑作战包] → 调整话术/替换产品/增删线索（会前最后修改）
│   └── [返回] → 回到客户画像/工作台
│
└── 跳转逻辑：点击 [开始面谈] → APP进入"面谈中"状态
    · 开始计时（面谈时长记录）
    · 顶部状态栏变色提示"面谈进行中"
    · 锁定作战包版本（面谈中不再自动更新内容）
```

```

        ↓
┌─────────────────────────────────────┐
```

**P5 线索切换面板 设计要点：**
- 浮层弹出，不离开主界面
- 每条线索显示：序号 + 标题 + 状态图标（✅已完成 / ▶进行中 / ⏸未开始）
- 已完成线索自动标记（客户经理点过"完成此线索"后）
- 支持手动标记完成/跳过
- 选择后关闭面板，主界面切换到目标线索

```

        ↓
客户经理扫一眼偏离预制区 → 找到匹配的偏离选项
        ↓
点击选项，如：「○ 钱已经安排/转走了」
        ↓
┌─────────────────────────────────────┐
│ P3 偏离详情卡片（从底部滑入，半屏）    │
│                                     │
│ 📍 偏离：钱已转走                     │
│                                     │
│ 💬 应对话术                          │
│ "了解了王先生，方便问一下这笔钱...    │
│                          [复制]      │
│                                     │
│ 🎯 策略调整                          │
│ · 先追问资金去向，不急于推销          │
│ · 买房 → 推短期灵活/按揭             │
│ · 转他行 → 了解原因，对比优势         │
│                                     │
│ 📦 备选产品 (3只)                    │
│ ┌──────┐ ┌──────┐ ┌──────┐        │
│ │现金管│ │短期理│ │按揭贷│        │

│ └──────┘ └──────┘ └──────┘        │

└─────────────────────────────────────┘
```

**P3 偏离详情卡片 跳转逻辑：**

| 操作 | 跳转目标 | 说明 |
|------|---------|------|
| [返回当前剧本] | 回到 P2，当前线索不变 | 客户偏离被处理完，继续按原剧本推进 |
| [切换为新线索] | 回到 P2，但议程调整 | 当前线索标记为"已处理"，将偏离触发的新需求插入议程 |
| 点击某只备选产品 | 展开该产品的 P4 展示模式 | 直接给客户看新产品 |
| 点击 [复制] | 无跳转，话术复制到剪贴板 | 客户经理可粘贴到微信或其他地方 |

**偏离也分为已有匹配和未匹配**：
```

        ↓

        ↓

│ ⚠ 面谈后将提醒您补充此偏离场景        │
└─────────────────────────────────────┘
```

**P4 展示模式页 跳转逻辑：**

| 操作 | 跳转目标 | 说明 |
|------|---------|------|
| [🔒 切回私密] | 回到 P2 面谈主界面 | 恢复私密模式，显示内部分析和话术 |
| [← 上一只] [下一只 →] | P4 内切换 | 在同一线索的推荐产品列表内滑动 |
| [比一比] | P4 内展开对比视图 | 展示模式下勾选2只产品并排对比（产品对比的展示模式版本） |
| 客户经理把手机转回来 | P2 面谈主界面 | 如启用姿态检测，自动切回私密模式 |

**从展示模式退出到不同状态**：
- 如果展示的产品是原剧本的推荐产品 → 回到 P2 当前线索
- 如果展示的产品是偏离后新匹配的产品 → 回到 P3 偏离详情卡片（方便继续处理偏离）

### Step 7：与客户确认要点（可选步骤）

> **定位**：面谈收尾时的一个增值环节。客户经理可选择生成一份给客户看的"交流要点记录"，跟客户一起快速回顾、确认，然后结束面谈。这个动作让客户感觉被尊重、有闭环，提升专业形象。

**触发时机**：P7 面谈结束页中点击 [生成客户确认要点]，或客户经理主动在结束前选择此操作。

**设计原则**：
- **可选而非强制**：不是每个客户都适合（如快速寒暄型客户），客户经理自行判断
- **客户视角**：只展示客户关心的事，不做内部汇报
- **确认即信任**：客户过目确认的过程本身就是建立信任的动作
- **可分享**：确认后可一键转发给客户（微信等），留下书面备忘

**P9 客户确认要点页 → 跳转逻辑：**

| 操作 | 跳转目标 | 说明 |
|------|---------|------|
| [编辑内容] | P9 内编辑态 | 客户经理可修改AI生成的内容（增减要点、调整措辞）后再确认 |
| [分享给客户] | 唤起系统分享面板 | 生成干净版图片/文本，通过微信或其他渠道发送 |
| [仅我确认] | 回到 P7 面谈结束页 | 客户经理自己确认记录，不与客户分享 |

**P9 与 P4 展示模式的区别：**

| 维度 | P4 展示模式（产品） | P9 确认要点（面谈收尾） |
|------|------|------|
| **时机** | 面谈中，给客户看产品 | 面谈结束时，与客户确认总结 |
| **目的** | 辅助产品介绍 | 确认共识、闭环体验 |
| **内容** | 单只或多只产品信息 | 本次交流总结+后续待办 |
| **交互** | 客户经理主导讲解 | 双方共同确认 |
| **提示条颜色** | 绿色（展示中） | 蓝色（确认中） |
| **分享** | 通常不分享 | 支持一键分享给客户 |

**为什么这个设计重要：**

```
不做的体验：
  面谈结束 → 客户经理说"那我回头联系您" → 客户离开
  客户回家后："今天聊了什么来着？那个人说什么时候联系我？"
  → 模糊、不可靠、容易遗忘

做了的体验：
  面谈结束 → "王先生，我帮您整理了一下今天聊的要点，您过目看看"
  → 一起过目确认 → "我微信发给您，方便您随时查看"
  → 客户手机收到一份清晰的记录
  → 专业、可信赖、有闭环
```

**一期建议**：P9 作为可选功能，在 P7 面谈结束页中提供一个明显的入口。客户经理可根据客户类型自行判断是否使用（如高净值客户、新客户更适合此流程；熟客、快速咨询型客户可跳过）。

## 五、各页面关键设计约束

| 页面 | 关键约束 |
|------|---------|
| **P2 面谈主界面** | 所有信息在一屏内，不滚动；偏离预制区常驻可见；操作按钮大，方便单手点击 |
| **P3 偏离详情卡片** | 半屏弹出（保留上半屏可以看到客户）；话术字号偏大可直接念；策略用列表不超3条 |
| **P4 展示模式页** | 字号+2档；无任何内部标签/策略/合规文字；有绿色提示条防止忘记退出；支持横屏 |
| **P5 线索切换面板** | 浮层弹出，不离开主界面；清晰的状态标记（✅/▶/⏸）；支持跳过和重排 |
| **P6 快速记录浮层** | 最小化干扰；支持快捷标签（点击即添加，不输入文字也能标记）；自动暂存 |
| **P7 面谈结束页** | 分步骤引导（小结→补充偏离→创建任务→更新标签）；每一步可跳过；最终确认后不可逆 |
| **P8 兜底搜索** | 使用频率最低，作为降级方案存在；简洁不复杂 |
| **P9 客户确认要点** | 展示模式风格，蓝色提示条；编辑态允许调整措辞；支持一键分享（图片/微信） |

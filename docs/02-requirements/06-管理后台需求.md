## 一、用户角色与权限分层体系

### 1.1 角色定义

| 角色 | 管辖范围 | 核心诉求 |
|------|---------|---------|
| **总行管理者** | 全行 | 全局经营态势总览、战略目标下达与跟踪、分行对标排名、标杆发现与全行推广 |
| **分行管理者** | 本分行及下辖支行 | 辖内目标分解与进度管控、支行对标排名、重点商机与客户分布、套路本地化适配 |
| **支行/网点管理者** | 本支行及下辖客户经理 | 团队任务分配与督导、客户经理排名与绩效、客户管户关系维护、个体辅导与赋能 |

### 1.2 权限控制原则

- **数据可见性**：管理者只能查看其分管机构范围内的数据（含下级机构汇总数据）
- **操作权限**：管理操作（如目标下达、管户调整、套路推广）仅限管辖范围内生效
- **"向下穿透"原则**：上级可逐层穿透查看下级数据，不可越级向上查看
- **敏感字段脱敏**：客户姓名、联系方式等敏感信息在列表视图中默认脱敏，详情页按角色控制

## 二、机构任务目标管理

### 2.1 目标体系

与前台"商机闭环"（考核目标 → 转化率 → 所需商机数 → 客户基数）对应，后台需建立自上而下的目标管理链路：

```
总行年度/季度目标
    ↓ 分解
分行目标（AUM增量、产品销量、客户新增等）
    ↓ 分解
支行目标
    ↓ 分解到人
客户经理个人目标
    ↓ 映射到前台
每日待办清单 + 商机挖掘闭环（前台已设计）
```

### 2.2 主要功能

| 功能点 | 说明 |
|-------|------|
| **目标模板管理** | 预定义考核指标模板（AUM净增、理财产品销量、基金销量、保险销量、贵宾客户新增数、有效户转化数等），支持按年度/季度配置 |
| **目标逐级下达** | 上级选择下级机构，设定各指标目标值；支持按绝对值或增长率设定 |
| **AI 目标分解建议** | AI 基于历史完成数据、客户经理能力系数、辖内客户资源分布，自动生成"公平型"（按资源等比分配）和"激励型"（高能力者多扛）两种分解方案供管理者选择 |
| **目标分解视图** | 树形结构展示"总行 → 分行 → 支行 → 客户经理"的目标分解链路，直观看到每个层级的承接关系 |
| **目标调整与审批** | 支持季度中调整目标，需上级审批 |
| **完成进度实时统计** | 自动聚合下级上报/系统采集的完成数据，计算完成率、缺口金额/数量 |

### 2.3 关键业务规则

- 下级目标汇总 ≥ 上级目标（确保目标不悬空）
- 客户经理目标 = 支行目标 / N（可按客户经理能力系数加权分配）
- 完成数据 T+1 日自动汇总（来自核心系统/数仓）

## 三、商机统计与分析

### 3.1 商机数据视图

与前台"商机三来源"（系统推送、客户经理创建、AI智能挖掘）对齐，后台提供管理者视角的商机全貌：

| 统计维度 | 说明 |
|---------|------|
| **商机总量与分布** | 按来源分类（系统推送/人工创建/AI挖掘）、按类型分类（代发到账/流失预警/产品到期/自定义等） |
| **商机状态分布** | 待跟进 / 已生成作战包 / 已触达 / 已转化 / 已流失，各状态数量与占比 |
| **商机转化漏斗** | 商机总数 → 已生成作战包 → 已触达 → 已转化，各级转化率 |
| **商机价值预估** | 所有活跃商机的潜在AUM增量汇总（按商机关联的预估金额累加）|
| **商机趋势分析** | 按周/月展示新增商机数、转化数、流失数的趋势曲线 |

### 3.2 商机明细列表

- 支持按机构、客户经理、商机类型、状态、金额区间筛选
- 列表展示：客户姓名（脱敏）、商机类型、来源、预估金额、当前状态、负责客户经理、创建时间
- 支持导出 Excel

## 四、客户管理与管户关系

### 4.1 重点客户清单

| 功能点 | 说明 |
|-------|------|
| **客户分层视图** | 按资产规模（私行/财富/贵宾/大众）、客户等级进行分层展示 |
| **资产排名** | 辖内客户按AUM降序排列，支持筛选Top N |
| **客户画像速览** | 点击客户可查看简要画像（与前台客户洞察数据同源）：总资产、产品持仓分布、近6月AUM趋势、最近沟通记录摘要 |
| **贡献度排名** | 按客户贡献的收入/利润排名（需对接绩效考核系统数据）|
| **流失预警客户清单** | 展示辖内命中流失模型的客户清单及流失概率，支持分配给客户经理跟进 |

### 4.2 客户管户关系管理

| 功能点 | 说明 |
|-------|------|
| **管户关系查询** | 按客户经理查看其名下管户清单，按客户查看其归属客户经理 |
| **管户分配** | 将未分配客户（新客户/无人管户）分配给指定客户经理 |
| **管户调整** | 将客户从客户经理A调整至客户经理B（如人员离职、调岗、客户升级等场景） |
| **批量分配** | 按规则（如按地域、按资产段、按客户等级）批量分配客户 |
| **分配记录与追溯** | 完整记录每次管户变更的时间、操作人、原因 |
| **管户上限预警** | 当某客户经理管户数超过设定上限时预警提示 |

## 五、多维数据看板

### 5.1 任务完成情况看板

- **核心指标卡**（顶部）：辖内AUM净增（完成率%）、重点产品销量（完成率%）、客户新增数（完成率%）
- **完成趋势图**：各指标按周/月的完成进度曲线 vs 目标线
- **缺口分析**：当前距季度/年度目标的缺口，按机构/客户经理下钻
- **与前台的关联**：客户经理个人目标完成率 = 前台"商机闭环"中"考核目标完成情况"的输入参数

### 5.2 管辖机构任务完成排名看板

- **排名列表**：按完成率降序排列下辖各机构，展示机构名、各指标完成率、综合得分
- **红黄绿预警**：完成率 < 60% 红色、60%-90% 黄色、≥ 90% 绿色
- **支持切换排名维度**：AUM净增排名 / 产品销量排名 / 客户新增排名 / 综合排名
- **趋势对比**：当前排名 vs 上期排名变化（↑↓箭头）
- **AI排名解读**：自动解读排名升降的原因，标注主要贡献因子

### 5.3 客户经理任务完成排名看板

- **排名列表**：按完成率降序排列辖内客户经理，展示姓名、所属机构、各指标完成率
- **个人详情下钻**：点击客户经理可查看其名下的待办完成率、商机转化率、客户触达率等前台行为数据
- **排行榜时效**：T+1 更新

### 5.4 客户价值/贡献分层看板

- **金字塔图**：按AUM分层展示客户数量与资产占比（私行/财富/贵宾/大众）
- **客户迁徙分析**：本期客户层级变动（升级/降级/流失）的数量与金额
- **客户贡献Top N**：辖内贡献度最高的前20/50/100名客户
- **沉睡客户激活统计**：本期从"无交易"变为"有交易"的客户数量及唤醒金额

### 5.5 商机统计分析看板

- **商机概览卡片**：辖内活跃商机总数、预估总价值、本月新增、本月已转化
- **商机来源分布**：饼图展示系统推送/人工创建/AI挖掘三类来源占比
- **商机转化漏斗**：各阶段数量与转化率
- **商机类型热力图**：按机构 × 商机类型交叉展示商机密度
- **AI挖掘效果评估**：AI挖掘商机的转化率 vs 系统推送商机的转化率对比（评估AI推荐质量）

## 六、洞察-提炼-推广主线

> **定义**：在"目标管控与排名统计"之外，建立一条从"发现优秀做法 → 提炼可复制套路 → 全行推广落地"的管理赋能闭环，让管理后台不仅是"监控器"，更是"方法工厂"。

### 6.1 主线总览

```
洞察（看过程）          提炼（找方法）          推广（规模化）
──────────────────  →  ──────────────────  →  ──────────────────
下级工作行为数据         识别高绩效行为模式       将套路打包为模板/规则
商机转化路径分析         提取可复制的打法         下发给全员或指定范围
客户经营策略对比         总结标杆案例            跟踪采纳率与效果
作战包使用效果评估       沉淀为AI推荐依据         持续迭代优化
```

与原有"目标-排名"主线的区别：

| 维度 | 目标-排名主线 | 洞察-提炼-推广主线 |
|------|-------------|-------------------|
| **关注点** | 结果（完成了多少） | 过程（怎么完成的、为什么完成得好） |
| **管理者角色** | 考核者、监督者 | 教练、方法赋能者 |
| **产出物** | 排名表、完成率报表 | 最佳实践、话术模板、策略规则 |
| **对前台的影响** | 间接（压力传导） | 直接（AI推荐、作战包、排程策略优化） |
| **数据时效** | T+1 报表 | 准实时 + 周期性分析 |

### 6.2 洞察层：下级工作过程透视

#### 客户经理工作行为画像

| 洞察维度 | 数据来源 | 分析内容 |
|---------|---------|---------|
| **时间分配结构** | 待办处理记录（processing_records）| 各类待办耗时占比、黄金时段利用率、碎片时间 vs 整块时间分布 |
| **触客方式偏好** | 电话/微信/面谈执行记录 | 不同场景下的触客方式选择倾向，与转化效果交叉分析 |
| **日程执行纪律** | AI排程建议 vs 实际执行偏差 | 排程遵从度、任务延期/跳过频率、紧急任务响应速度 |
| **商机跟进节奏** | 商机状态流转时间戳 | 商机生成→首次触达间隔、触达→转化周期、多次触达频率 |
| **作战包使用深度** | 作战包打开/编辑记录 | 是否只是"看一眼"还是做了个性化调整，标准版使用频率 |

#### 商机转化路径分析

追踪"商机 → 作战包 → 执行 → 转化"全链路中的关键分叉点：响应时效（立即/延迟/超过3天）、触达方式（电话/微信/面谈）、触达次数（一次/多次），对比各路径转化率差异。管理者可据此发现"哪类商机响应越快转化越高""哪种触客方式对哪类商机最有效""高转化客户经理的黄金跟进节奏"。

#### 客户经营策略对比

| 对比维度 | 说明 |
|---------|------|
| **客户触达频次分布** | 按高频/中频/低频触达分组，对比各组客户的AUM增长率、流失率 |
| **产品推荐策略** | 高转化客户经理在作战包中偏向"聚焦1-2款主推"还是"广撒网多推荐"？各自效果如何 |
| **面谈议程执行** | 客户经理是严格按AI建议的议程走，还是经常跳过/调整？调整后的效果更好还是更差 |
| **跨品类经营能力** | 客户经理是"理财专家"还是"全品类经营"？客户资产分布是否更多元 |

#### 洞察看板设计

管理后台增加「**工作洞察**」一级导航，包含以下子看板：

1. **行为对比看板**：散点图/矩阵图，X轴为行为指标（如"首次触达平均响应时长"），Y轴为结果指标（如"转化率"），每个点代表一名客户经理，一键识别标杆和需改进对象

2. **商机转化漏斗对比**：将辖内客户经理按绩效分位（Top 20% / Mid 60% / Bottom 20%），并排展示三组的转化漏斗，自动标注差异最大的阶段

3. **客户经营健康度雷达图**：每位客户经理一张六维雷达图（管户触达覆盖率、产品交叉销售率、客户升级率、流失预警响应率、待办完成准时率、作战包使用深度）

### 6.3 提炼层：从优秀做法到可复制套路

#### 标杆自动识别

| 识别规则 | 说明 |
|---------|------|
| **绩效Top + 过程优秀** | 业绩排名前20% 且 过程指标也排名前30% |
| **特定维度标杆** | "流失挽回率最高"、"新客转化最快"、"理财产品销售最稳"等单项冠军 |
| **进步最快标杆** | 本期 vs 上期提升幅度最大的客户经理 |
| **异常发现** | 业绩一般但某项过程指标特别突出的（方法好但管户质量差，方法值得提炼） |

#### 行为模式提炼

| 提炼方向 | 具体内容 | 输出物 |
|---------|---------|-------|
| **高效排程模式** | 标杆如何安排一天的待办处理顺序？同类任务集中处理还是穿插？ | 排程策略模板 |
| **高转化话术** | 哪类切入话术在某类商机上转化率显著高于平均？提取共性关键词 | 话术优化建议 |
| **高效产品组合** | 标杆在作战包中最常推荐的产品组合及接受率 | 产品组合推荐规则 |
| **触达时机规律** | 标杆触达行为在时间维度上的分布特征（周几、几点、间隔多久） | 智能排程时间权重 |
| **客户经营节奏** | 标杆对新客、存量客户、流失预警客户的经营节奏差异 | 客户分层经营SOP |

#### 套路库管理

管理后台建立「**套路库**」模块，结构化存储和版本管理：

```
套路库
├── 排程策略模板
│   ├── "上午集中处理紧急待办，下午安排面谈"（来源：标杆A，采纳率 67%）
│   ├── "同类待办批量处理，每次不超过5个"（来源：标杆B，采纳率 52%）
│   └── ...
├── 作战包策略模板
│   ├── "代发到账商机：以利率对比切入，主推R2理财 + 现金管理过渡"（转化率提升23%）
│   ├── "流失预警商机：先关怀再推荐，首通电话不推销"（挽回率 41%）
│   └── ...
├── 话术精华库
│   ├── 高转化切入话术（按商机类型分类）
│   ├── 异议应对话术（按常见客户疑虑分类）
│   └── 产品介绍话术（按产品类型分类）
├── 客户经营SOP
│   ├── 新客首月经营节奏
│   ├── 贵宾客户季度经营计划
│   └── 流失预警客户挽回流程
└── 管理者自定义
    └── 管理者可手动创建、编辑、标记为"已验证"的套路
```

### 6.4 推广层：从套路到规模化落地

#### 推广机制

```
套路库（管理后台）
      │
      ├──→ AI智能排程引擎    → 排程策略模板影响前台每日日程的生成逻辑
      ├──→ 作战包生成引擎    → 产品组合/话术/策略模板融入作战包内容
      ├──→ 话术推荐引擎    → 高转化话术进入前台对话式AI的话术库
      ├──→ 商机推送规则引擎  → 调整系统推送商机的优先级与匹配逻辑
      └──→ 客户经营SOP引擎  → 影响待办生成规则和触达提醒策略
```

#### 推广任务管理

| 功能点 | 说明 |
|-------|------|
| **推广范围设定** | 全行 / 指定分行 / 指定支行 / 指定客户经理分组 |
| **推广方式** | 强制应用 / 默认推荐（客户经理可调整） / 灰度发布（A/B测试分批推送） |
| **发布时间** | 立即发布 / 定时发布 / 按版本迭代 |
| **推广通知** | 推送后在前台以横幅/角标通知客户经理"已有新的推荐策略可用" |

#### 效果跟踪与闭环

| 跟踪指标 | 说明 |
|---------|------|
| **采纳率** | 目标群体中实际使用该套路的人数占比、使用频次 |
| **效果对比** | 采纳组 vs 未采纳组的绩效差异，验证套路有效性 |
| **衰减监控** | 套路效果是否随时间衰减（如话术的边际效用递减） |
| **变异分析** | 客户经理是否在套路基础上做了个性化修改？修改后的效果更好还是更差 |

#### A/B实验能力（高阶）

- 选择实验组和对照组（按机构/客户经理分层随机）
- 设定实验周期和核心观测指标
- 实验结束后自动输出显著性报告
- 决策：全量推广 / 终止 / 调整后重新实验

## 七、管理者工作台构成分析

> **设计理念**：三个层级的管理者虽然共用同一后台系统，但因管辖范围和管理重心不同，工作台的首页构成应有差异化——让不同层级的管理者打开后台时，第一眼看到的是他**最需要关注的信息**和**最常用的操作入口**。

| 客户管理 | 重点客户清单、大额客户预警 | 管户关系维护、管户分配调整 |
| 待办侧重 | 审批、异常处置 | 管户分配、人员辅导、重大商机协同 |

---

### 7.5 三级工作台差异化设计总结

| 维度 | 总行 | 分行 | 支行 |
|------|:---:|:---:|:---:|
| **数据粒度** | 分行级汇总 | 支行级汇总 | 客户经理个人级 |
| **排名对象** | 分行 | 支行 + 客户经理 | 客户经理 |
| **排名关注** | 整体分布与趋势 | 内部对标 + 找差距 | 每人每天的状态 |
| **AI核心能力** | 诊断 + 预测 + 标杆发现 | 归因 + 预测 + 套路管理 | 辅导建议 + 个体诊断 |
| **AI报告生成** | 全行季报/年报 | 分行周报/月报 | 支行日报/周报 |
| **套路角色** | 创建者/发布者 | 适配者/推广者 | 消费者/反馈者 |
| **行为洞察** | 看全行行为分布 | 找辖内标杆与落后 | 每日团队行为概览 |
| **客户管理** | 全行Top客户 + 分层结构 | 大额客户预警 + 分层 | 管户关系维护 |
| **待办类型** | 战略审批、重大决策 | 分解审批、异常处置、人员管理 | 管户分配、协同跟进、团队辅导 |
| **刷新频率** | 日/周 | 日 | 准实时 |

## 八、AI 智能化赋能全景

> **概述**：在管理后台的"目标-排名"和"洞察-提炼-推广"两条主线上，全面植入AI能力，将管理后台从"报表查询工具"升级为"智能决策辅助平台"。共计 12 个 AI 应用场景，覆盖经营诊断、洞察提炼、内容生成、对话交互四大领域。

### 8.1 AI 赋能全景地图

```
              目标-排名主线              洞察-提炼-推广主线
                 （管结果）                  （管方法）
        
 分析决策层  ┌─────────────────┐    ┌─────────────────┐
            │ AI经营诊断      │    │ AI标杆自动发现   │
            │ AI归因分析      │    │ AI行为模式挖掘   │
            │ AI预测预警      │    │ AI策略效果评估   │
            └─────────────────┘    └─────────────────┘

 内容生成层  ┌─────────────────┐    ┌─────────────────┐
            │ AI报告自动生成   │    │ AI套路自动提炼   │
            │ AI复盘材料       │    │ AI话术精华提取   │
            │ AI目标分解建议   │    │ AI辅导建议生成   │
            └─────────────────┘    └─────────────────┘

 交互入口层  ┌─────────────────────────────────────────┐
            │        管理后台 AI 对话助手               │
            │  自然语言查数据 / 问排名 / 要分析 / 找原因  │
            └─────────────────────────────────────────┘
```

### 8.2 四大领域 · 十二场景

#### 领域一：AI 经营诊断与预测（分析决策 · 目标-排名主线）

**场景 1：AI 经营健康度自动诊断**

自动扫描辖内所有指标，识别异常波动并输出诊断结论。输入为当期经营数据、历史同期数据、目标值、同级机构均值；输出为"诊断简报"——红灯指标排序、黄灯预警、同级对比落后项。在看板顶部以 AI 诊断卡片形式呈现。

**场景 2：AI 归因分析**

对异常指标自动下钻，多维度交叉分析（客户分层变动、产品销售结构、客户经理行为数据等），推导可能原因并给出置信度排序。点击异常指标时弹出归因分析面板，支持追问深挖。

**场景 3：AI 预测预警**

基于历史趋势和当前节奏，预测期末各指标达成概率，提前预警缺口。输出示例："按当前节奏，Q3末AUM净增预计完成 82%，缺口约 1,800 万。需新增约 12 个有效商机。"预测缺口可触发前台"商机闭环"中所需商机数量的动态调整。

**场景 4：AI 智能排名解读**

对比本期 vs 上期排名变化，自动解读升降原因并标注主要贡献因子。在排名看板中内嵌，点击"解读"即可展开。

---

#### 领域二：AI 洞察提炼与策略推荐（分析决策 · 洞察-提炼-推广主线）

**场景 5：AI 标杆自动发现与画像**

基于多维行为数据 + 绩效数据交叉分析，自动识别综合标杆、单项冠军、进步最快标杆，并为每类标杆生成"AI行为画像"——他与平均水平的差异和独门秘籍。在"标杆发现"看板中展示。

**场景 6：AI 行为模式挖掘**

将标杆组 vs 对照组的行为数据进行统计对比和模式识别，自动提取差异化行为特征，按显著性排序，高亮"可干预的关键行为"。输出为AI行为对比报告。

**场景 7：AI 套路自动提炼**

从标杆行为数据 + 前台对话记录/作战包内容中，自动提取可复制的模式，生成结构化套路初稿（套路名称、适用场景、核心打法、关键话术、数据支撑）。管理者审核编辑后入库推广。AI持续追踪采纳率和效果，自动标记"效果衰减"或"发现更优变体"。

**场景 8：AI 辅导建议生成**

基于客户经理个体行为画像 vs 同级均值/标杆画像，自动生成"一人一策"辅导建议——核心短板、推荐套路、优势发挥、建议观察周期。支行管理者可基于建议修改后一键推送给客户经理。

---

#### 领域三：AI 内容生成（提效降本 · 横向支撑）

**场景 9：AI 经营报告自动生成**

基于看板数据 + AI归因分析 + 预测预警结果，自动生成结构化经营分析报告（经营概览、亮点、不足与归因、风险预警、下期建议）。选择报告周期和范围后流式生成，管理者审阅编辑后可导出/分发。

**场景 10：AI 复盘材料生成**

生成季度复盘会/述职会用材料，包括业绩快报、AI自动选取的标杆案例摘要、问题剖析、同业对标、下季目标建议。

**场景 11：AI 目标分解建议**

基于历史完成数据、客户经理能力系数、辖内客户资源分布，自动生成"公平型"和"激励型"两种目标分解方案供管理者选择。

---

#### 领域四：AI 对话交互（交互入口 · 全局覆盖）

**场景 12：管理后台 AI 对话助手（"管理驾驶舱副驾"）**

管理后台右下角悬浮按钮 → 展开侧边AI对话面板，支持自然语言查数据、问排名、要分析、找原因、生成报告等。与前台的"徽小助"对话助手形成品牌呼应，但适配 Web 端侧边栏形态。

**典型对话示例：**
```
管理者: "XX分行这个月表现怎么样？"
AI:     "XX分行本月AUM净增+320万，完成率78%，辖内排名第3/6。
        亮点：理财产品销量超额完成112%。不足：客户新增仅45%。
        需要我展开分析客户新增落后的原因吗？"

管理者: "给我写一份本周的经营简报"
AI:     [生成结构化周报，管理者可编辑后导出]

管理者: "帮我对比Top5和Bottom5客户经理的行为差异"
AI:     [自动生成行为对比报告，含显著性排序]
```

### 8.3 AI 场景落地优先级

| 阶段 | 场景 | 理由 |
|:---:|------|------|
| **Phase 1**<br>快速建立AI感知 | 场景12 AI对话助手（数据查问）<br>场景1 AI经营健康度诊断<br>场景3 AI预测预警 | 基于结构化数据，技术难度可控，管理者感知强烈 |
| **Phase 2**<br>分析能力升级 | 场景2 AI归因分析<br>场景4 AI排名解读<br>场景11 AI目标分解 | 深化从"看数据"到"读数据"的转变 |
| **Phase 3**<br>洞察闭环打通 | 场景5 AI标杆发现<br>场景6 AI行为模式挖掘<br>场景8 AI辅导建议 | 打通"洞察-提炼-推广"主线的核心环节 |
| **Phase 4**<br>直接提效降本 | 场景9 AI报告生成<br>场景10 AI复盘材料 | 高频刚需，节省管理者大量文案时间 |
| **Phase 5**<br>深度智能突破 | 场景7 AI套路自动提炼 | 技术难度最高（需NLP+对话理解+模式归纳），但价值最大 |

### 8.5 关键技术考量

| 考量点 | 说明 |
|-------|------|
| **数据基础** | 严重依赖客户经理行为数据（processing_records、作战包使用日志、商机流转日志、AI对话记录），需在前台原型阶段就设计好埋点 |
| **隐私与合规** | 客户对话记录用于AI分析时需脱敏；AI辅导建议不直接暴露客户敏感信息 |
| **可解释性** | 所有AI分析结论必须附带"为什么"——如归因分析展示置信度和推导链路，避免"黑盒决策" |
| **人机协作边界** | AI 做分析和建议，管理者做判断和决策。目标分解、套路推广、辅导方案等均需人工确认 |
| **交互一致性** | 管理后台 AI 对话助手与前台"徽小助"保持品牌一致，在视觉和交互上适配 Web 端（侧边面板 vs 底部浮层） |

## 九、管理者待办任务（预留）

> 本模块暂不详细设计，后续专题细化。

### 9.1 初步方向

管理者待办不同于客户经理的"执行类待办"，而是"审批/决策/关注类"任务：

| 待办类型 | 触发场景 | 示例 |
|---------|---------|------|
| **目标审批** | 下级提交目标调整申请 | "XX支行申请调降Q3理财产品销售目标" |
| **管户分配审批** | 批量管户调整需上级确认 | "XX分行提交了23户客户批量重新分配方案" |
| **异常预警处置** | 系统发现异常指标需关注 | "XX支行本月AUM净增为负"、"赵强连续2周待办完成率<50%" |
| **商机升级审批** | 大额商机需管理介入 | "客户王建国的流失预警商机涉及AUM 800万，建议协同跟进" |
| **周期性复盘提醒** | 按周/月推送 | "本周辖内商机转化报告已生成"、"月度机构排名报告已生成" |
| **套路审核** | AI提炼新套路待人工审核 | "AI发现了一个潜在的高效话术模式，请审核是否入库推广" |

### 9.2 设计原则

- 管理者待办与客户经理待办共用底层任务模型，在类型分类、优先级、处理动线上做差异化设计
- 优先级规则：审批类 > 异常预警 > 周期性复盘
- 部分待办支持"一键处理"（如确认已阅），部分需跳转详情页操作

## 十、非功能性需求

| 维度 | 要求 |
|------|------|
| **运行环境** | Web端，兼容 Chrome 89+、Edge 89+、360安全浏览器、统信UOS（与前台要求一致） |
| **数据时效** | 统计看板 T+1 更新，商机/待办类数据准实时；AI诊断每日刷新 |
| **数据权限** | 严格按机构层级隔离，接口层与前端双层校验 |

| **导出能力** | 所有列表/排名视图支持导出 Excel；AI报告支持导出 PDF/Word |
| **AI响应时效** | AI诊断/归因分析 ≤ 5秒；AI报告生成支持流式输出，首字响应 ≤ 3秒 |

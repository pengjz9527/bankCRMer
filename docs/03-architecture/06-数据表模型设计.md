## 二、域详细设计

### 2.1 客户基础域

#### customers（客户主表）

| 字段 | SQLite 类型 | 约束 | 说明 |
|:---|:---|:---|:---|
| `id` | INTEGER | PK AUTOINCREMENT | 客户 ID |
| `cust_no` | TEXT | NOT NULL UNIQUE | 客户号 |
| `name` | TEXT | NOT NULL | 姓名 |
| `age` | INTEGER | NOT NULL | 年龄 |
| `gender` | TEXT | NOT NULL CHECK(M/F) | 性别 |
| `occupation` | TEXT | — | 职业 |
| `industry` | TEXT | — | 行业 |
| `city` | TEXT | — | 城市 |
| `education` | TEXT | — | 学历 |
| `phone_masked` | TEXT | — | 脱敏手机号 |
| `tier` | TEXT | NOT NULL | 客户等级（千元以下/千元户/万元户/优质/财富/高净值/私钻/私行） |
| `total_aum` | REAL | NOT NULL DEFAULT 0 | 总资产（元） |
| `employment_status` | TEXT | DEFAULT '在职' | 就业状态 |
| `contact_prefer` | TEXT | DEFAULT '不限定' | 联系时段偏好 |

**索引**：`idx_cust_tier`(tier)

#### customer_channels（客户渠道可触达配置）

记录每个客户在每个渠道的签约/开通/关闭状态，作为渠道执行计划的**前置约束**。

| 字段 | SQLite 类型 | 约束 | 说明 |
|:---|:---|:---|:---|
| `id` | INTEGER | PK AUTOINCREMENT | — |
| `cust_id` | INTEGER | FK→customers.id | 客户 ID |
| `channel` | TEXT | NOT NULL | 渠道标识：sms / wecom / phone / onsite / app |
| `status` | TEXT | NOT NULL DEFAULT 'active' | active(已开通) / unsigned(未签约) / closed(客户关闭) |
| `closed_reason` | TEXT | — | 关闭原因（如"客户退订短信""客户拉黑企微""空号"） |
| `verified_at` | TEXT | — | 最近一次确认时间 |
| `updated_at` | TEXT | NOT NULL | 更新时间 |

**约束**：UNIQUE(cust_id, channel)
**索引**：`idx_cc_cust`(cust_id)、`idx_cc_channel`(cust_id, channel)

**状态变更触发规则**：
- 客户退订短信 → `sms.status = 'closed'`，`closed_reason = '客户退订'`
- 客户拉黑企微 → `wecom.status = 'closed'`，`closed_reason = '客户拉黑'`
- 手机号码空号 → `phone.status = 'closed'`，`closed_reason = '空号/停机'`
- 客户关闭 APP 推送 → `app.status = 'closed'`，`closed_reason = '客户关闭推送'`
- 客户经理添加企微成功 → `wecom.status = 'active'`

### 2.2 管户关系域

#### cust_manager_rel（客户经理归属）

**M:N 关系**：一位客户可有多个经理（主/协办），一位经理管多位客户。

| 字段 | SQLite 类型 | 约束 | 说明 |
|:---|:---|:---|:---|
| `cust_id` | INTEGER | FK→customers.id | 客户 ID |
| `manager_id` | TEXT | NOT NULL | 客户经理 ID（如 M001） |
| `manager_name` | TEXT | NOT NULL | 客户经理姓名 |
| `assigned_date` | TEXT | DEFAULT date('now') | 分配日期 |
| `is_primary` | INTEGER | DEFAULT 1 | 主客户经理 |

**约束**：UNIQUE(cust_id, manager_id)
**索引**：`idx_cmr_cust`(cust_id)、`idx_cmr_mgr`(manager_id)

#### customer_relations（客户间关系）

| 字段 | SQLite 类型 | 约束 | 说明 |
|:---|:---|:---|:---|
| `cust_id_a` | INTEGER | FK→customers.id | 客户 A |
| `cust_id_b` | INTEGER | FK→customers.id | 客户 B |
| `relation_type` | TEXT | NOT NULL | 同企业代发/亲属/资金往来/担保/同客户经理 |
| `evidence` | TEXT | — | 发现依据（自然语言） |
| `evidence_field` | TEXT | — | 依据来源字段 |

**索引**：`idx_relations_a`(cust_id_a)、`idx_relations_b`(cust_id_b)

### 2.6 产品与营销域

#### product_catalog（产品目录）

全局配置表，不关联客户。为作战包产品推荐提供候选池。产品数据来源于银行实际在售产品，通过爬虫采集后迁移入库。

| 字段 | SQLite 类型 | 约束 | 说明 |
|:---|:---|:---|:---|
| `id` | INTEGER | PK AUTOINCREMENT | 自增主键 |
| `product_id` | TEXT | NOT NULL UNIQUE | 产品唯一标识（如 CSB-LC-001） |
| `product_code` | TEXT | — | 产品代码（如 LC2024CSB001） |
| `product_name` | TEXT | NOT NULL | 产品全称 |
| `short_name` | TEXT | — | 产品简称 |
| `bank_name` | TEXT | — | 发行银行 |
| `issuer` | TEXT | — | 发行方/管理公司 |
| `category` | TEXT | NOT NULL | 产品大类（理财/存款/保险/基金） |
| `sub_category` | TEXT | — | 产品子类（如固定收益类/混合类） |
| `risk_level` | TEXT | — | 风险等级 R1-R5 |
| `risk_name` | TEXT | — | 风险等级名称（如"低风险"） |
| `term_days` | INTEGER | — | 产品期限（天） |
| `term_desc` | TEXT | — | 期限描述（如"91天""活期"） |
| `min_amount` | REAL | DEFAULT 1 | 起购金额（元） |
| `min_amount_desc` | TEXT | — | 起购金额描述（如"1元起购"） |
| `expected_return_min` | REAL | — | 预期/历史收益率下限 |
| `expected_return_max` | REAL | — | 预期/历史收益率上限 |
| `yield_rate` | REAL | — | 参考收益率（便利字段，取值同 expected_return_max） |
| `return_type` | TEXT | — | 收益类型（固定收益/浮动收益） |
| `return_benchmark` | TEXT | — | 收益基准说明 |
| `currency` | TEXT | DEFAULT 'CNY' | 币种 |
| `invest_direction` | TEXT | — | 投资方向/资产投向 |
| `subscription_fee` | TEXT | — | 申购费率 |
| `redemption_fee` | TEXT | — | 赎回费率 |
| `redemption_days` | TEXT | — | 赎回到账天数 |
| `selling_points` | TEXT(JSON) | — | 产品卖点列表，JSON 数组 |
| `scenario_tags` | TEXT(JSON) | — | 适用场景标签，JSON 数组 |
| `applicable_customer` | TEXT(JSON) | — | 适用客群画像，JSON 对象 |
| `source_url` | TEXT | — | 数据来源 URL |
| `data_source` | TEXT | — | 数据来源标识 |
| `data_date` | TEXT | — | 数据采集日期 |
| `manager` | TEXT | — | 管理机构/客户经理归属 |
| `status` | TEXT | DEFAULT '在售' | 在售/停售/已停售（参考） |

**索引**：`idx_product_id`(product_id UNIQUE)

**注意**：
- `product_id` 是业务唯一标识（NOT NULL UNIQUE），`id` 是技术自增主键
- `category` 替代旧字段 `product_type`，取值：理财/存款/保险/基金
- `selling_points`、`scenario_tags`、`applicable_customer` 为 JSON 序列化字段，应用层读取后需反序列化
- `yield_rate` 为便利字段，默认取 `expected_return_max`，便于存量代码查询

## 五、SQLite vs PostgreSQL 差异

| 差异点 | SQLite (app.py) | PostgreSQL (schema.sql) |
|:---|:---|:---|
| 枚举类型 | TEXT + CHECK 约束 | CREATE TYPE … AS ENUM |
| 自增主键 | INTEGER PRIMARY KEY AUTOINCREMENT | SERIAL PRIMARY KEY |
| 计算列 | GENERATED ALWAYS AS (…) VIRTUAL | GENERATED ALWAYS AS (…) STORED |
| JSON 类型 | TEXT（存储 JSON 字符串） | JSONB（二进制 JSON） |
| 数组类型 | TEXT（存储 JSON 数组字符串） | TEXT[]（原生数组） |
| 布尔类型 | INTEGER (0/1) | BOOLEAN |
| 日期类型 | TEXT (ISO 8601) | DATE / TIMESTAMP |

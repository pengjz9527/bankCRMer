# 交互规格 — W2 日程处理与调整

> **定位**：Block 2 "今日日程安排"的深度交互设计。涵盖日程卡片处理、日程调整、全部待办分类列表三个子模块。
>
> **前置依赖**：W1 首页交互规格（已定义 Block 2 的展示层和跳转契约）
>
> **设计约束**：待办、商机、作战包的交互链路以《核心业务设计模型-待办商机作战包.md》为权威依据。
>
> **面向页面**：本规格中的交互均发生在首页 Block 2 区域内（浮层/面板模式），不跳转独立页面。
>
> **版本**：v1.0 | **最后更新**：2026-07-15

---

## 一、模块总览

```
Block 2 今日日程安排
├── 2.1 日程卡片处理交互
│   ├── 客户待办：点击卡片 → 处理面板（半屏浮层）
│   ├── 商机待办：点击卡片 → 跳转 P1 作战包
    ├── 工作待办：点击卡片 → 固定任务跳转到对应的URL（待定）
│   ├── 完成动效：翻转/消隐 → 轮播自动前进
│
└── 2.2 "全部待办"分类列表
    ├── 入口：[全部待办 >] 按钮
    ├── 按类型分组：客户待办 1 组 + 商机待办 1 组 + 工作待办 1 组
    └── 逐条处理：展开客户名单 → 逐条完成
```

## 二、模块 2.1：日程卡片处理交互

### 2.1.1 客户待办卡片 — 处理面板

**触发**：点击客户待办卡片上的 [开始处理] 按钮。

**交互形式**：从底部滑入半屏处理面板（不离开首页上下文）。

```
┌──────────────────────────────────────────┐
│ （首页内容变暗，半透明遮罩）               │
│                                          │
├──────────────────────────────────────────┤  ← 遮罩上方
│ 处理面板                          [关闭]   │
├──────────────────────────────────────────┤
│                                          │
│  ── 客户待办列表 ────────────────────────── │
│                                          │
│ ┌──────────────────────────────────────┐ │
│ │ ○ 王建国 · 男 · 45岁 · 金融业         │ │
│ │   XX定期存款 25万 · 7月18日到期(3天后) │ │
│ │   📞 电话  ✉️ 微信  ✓ 放入待办池 🟣画像  │ │  ← 四选一操作
│ └──────────────────────────────────────┘ │
│                                          │
│ ┌──────────────────────────────────────┐ │
│ │ ○ 张丽华 · 女 · 38岁 · 教育           │ │
│ │   YY悦享周期理财 10万 · 7月18日到期    │ │
│ │   📞 电话  ✉️ 微信  ✓ 放入待办池 🟣画像 │ │
│ └──────────────────────────────────────┘ │
│                                          │
│ ┌──────────────────────────────────────┐ │
│ │ ○ 赵明辉 · 男 · 52岁 · 制造业         │ │
│ │   ZZ大额存单 50万 · 7月25日到期        │ │
│ │   📞 电话  ✉️ 微信  ✓ 放入待办池 🟣画像  │ │
│ └──────────────────────────────────────┘ │
```

#### 处理面板交互元素

| 元素 | 行为 |
|------|------|
| 📞 电话 | 记录为"电话联系"方式处理 → 标记该客户待办完成 |
| ✉️ 微信 | 记录为"微信联系"方式处理 → 标记该客户待办完成 |
| ✓ 放入待办池 | 将该待办放回到待办池 → 标记该待办未添加到今日日程 |
| 🟣 画像 | 跳转到客户画像详情页，返回回到当前页面 |

#### 处理动效

| 步骤 | 动效 | 时长 |
|------|------|------|
| 点击操作按钮 | 按钮变为"处理中..."，背景变灰 | 即时 |
| 处理成功 | 按钮变为"✓ 已处理"绿色，客户行淡出 | 300ms |
| 该卡片所有客户处理完 | 面板自动关闭 → 首页该卡片翻转消隐 | 400ms |
| 轮播自动前进 | 轮播跳到下一张未处理卡片 | 350ms |

#### 处理结果回写

| 待办类型 | 完成后的系统动作 |
|------|------|
| 产品到期 | 标记为已处理，无后续 |
| 大额异动 | 标记为已处理，无后续 |
| 贷款逾期 | 标记为已处理，无后续 |
| 生日提醒 | 标记为已处理，无后续 |
| 联络超期 | 更新最后联络日期，无后续 |
| 信用卡待办 | 标记为已处理，无后续 |

> **设计约束**：普通待办完成后无回写，不产生商机状态变更

### 2.1.2 商机待办卡片 — 跳转商机详情页面

**触发**：点击商机待办卡片上的每一行商机信息的[详情] 按钮。

**行为**：从底部滑入半屏处理面板，展示该商机详情页面（不离开首页上下文）。。

┌────────────────────────────────────┐  
│ │ 📥 代发即将到账 · 来源：系统推送     │    ← 商机分组标题
│ │                                    │  
│ │ ┌──────────────────────────────────┐  │  
│ │ │ 赵明辉 · 男 · 52岁 · 制造业      │  │   ← 商机卡片
│ │ │ 近6月月均代发：32,000元          │  │
│ │ │ 最近代发：2026-07-15            │  │  
│ │ │ 预计下次：2026-07-17（2天后）    │  │  
│ │ │ 预估贡献：≈8万                  │  │  
│ │ │ [查看画像] [查看作战包] [放入待办池]  │  
│ │ └──────────────────────────────────┘  │ 

#### 商机详情页面交互元素
| 元素 | 行为 | 跳转目标 |
|------|------|------|
| 点击 [查看画像] | 跳转到该客户画像详情页 | 
| 点击 [查看作战包] | 跳转到该商机关联的作战包 | P1 作战包首页 |
| 点击 [放入待办池]| 将该待办放回到商机待办池 → 标记该待办未添加到今日日程 |

> **说明**：商机待办的完整处理流程在第四步 P1-P9 中设计。此处仅定义从 Block 2 到 P1 的跳转契约。

### 2.1.3 完成动效与轮播衔接

```
处理面板关闭
     ↓
卡片翻转/消隐动效（400ms）
     ↓
┌──────────────────────────────────────┐
│ 该卡片变为半透明 + "✓ 已完成"水印     │
│ 上方出现 TOAST："商机待办已处理" │
└──────────────────────────────────────┘
     ↓
TOAST 消失后（1.5s），轮播自动滑动到下一张未处理卡片
     ↓
如果所有卡片处理完毕：
┌──────────────────────────────────────┐
│ 轮播区替换为：                         │
│ "🎉 今日待办已全部完成"                │
│ "AI 已生成明日工作计划建议"            │
│ [查看明日计划]                         │
└──────────────────────────────────────┘
```

# 易会办 前台APP 交互设计规范 v1.0

> 本规范合并自 `设计规范.xlsx`（品牌红视觉体系）与 `design-system-spec.md`（v3.0 组件+交互体系），作为前台所有页面交互设计的唯一参考。
>
> 原型参考实现：`prototype/workbench.html`

---

## 一、设计理念

```
关键词：品牌红 · 任务驱动 · 智能排程 · 商机闭环 · 简洁明快

设计原则：
- 工作台 = 智能日程 + 商机看板，信息聚焦不堆砌
- AI 主动排程，客户经理按时间线执行即可
- 商机挖掘与考核目标形成闭环：目标 -> 缺口 -> 挖掘 -> 新客
- 品牌红为主色调，传递专业、可靠、温暖的金融服务感
- AI 能力用紫色独立标识，与品牌色形成层次区分
```

### 2.6 配色使用原则

```
1. Header
   -> 干净白底 + 底部 1px 分割线（不使用品牌色渐变）
   -> 如需品牌氛围，在 banner 区域使用品牌红渐变
   -> 问候语右侧可放置绿色呼吸灯指示 AI 在线状态

2. 品牌色渐变（color-primary-gradient）
   -> 限用于顶部 banner、重要功能图标背景
   -> 不做大面积纯色背景铺陈

3. AI 元素
   -> 统一使用紫色系（--color-ai / --color-ai-light）
   -> 与品牌红形成明确层次区分：红=业务操作，紫=AI 能力

4. 关键数字
   -> 金额、收益率等使用 --color-highlight（#F6434F）红色突出

5. 功能色
   -> 用于状态标签、提示、图标
   -> success/warning/danger 语义明确，不混用

6. 进度条
   -> 使用蓝色渐变（#3B82F6 → #60A5FA），表示"进度/正向指标"
   -> 不使用品牌红，与业务操作色形成语义区分

7. 时间标签
   -> 上午标签：粉色/浅红背景（#FFF0F0），深红文字（#C0392B）
   -> 下午标签：浅蓝/浅灰背景（#F0F4FF），深蓝文字（#3B5998）
   -> 传递时段感，与任务紧急度形成层次区分

8. 浮动 AI 按钮
   -> 右下角悬浮，紫色渐变 + 发光投影
   -> 独立于品牌色，暗示"AI 助手"

9. AI 标注
   -> 待办/商机上使用 AI 标签（"AI建议优先""AI推荐"）
   -> 紫色文字 + 浅紫色背景，小而精致
```

## 五、动效系统

| Token | 值 |
|------|------|
| `--ease-default` | `cubic-bezier(0.4, 0, 0.2, 1)`（等同 `ease`） |
| `--duration-fast` | `150ms` |
| `--duration-normal` | `250ms` |
| `--duration-slow` | `350ms` |

**规范值：** 全局统一使用 `0.3s ease`（源自设计规范.xlsx）。

**规则：**
- 所有动效使用相同的缓动函数
- 不做弹跳/回弹动效（金融产品需要稳重感）
- 过渡动画统一 0.3s（如导航栏背景切换）
- 点击反馈统一 150ms

## 六、组件规范

### 6.1 头部 Header

```css
.app-header {
  background: #ffffff;
  padding: 10px 15px 12px;
  box-shadow: 0 1px 0 #e5e5e5; /* 底部 1px 分割线 */
}
```

**规则：**
- 干净白底，不使用品牌色渐变（品牌红渐变限 banner 区域）
- 底部仅用 1px 分割线做层次区分
- 问候语字号 24px bold（一级标题），颜色 #333333
- 图标按钮背景色 `--color-bg`，按下变 `--color-divider`
- 可放置客户经理选择器（select 下拉），字号 11px

### 6.2 品牌 Banner（header-banner）

```css
.header-banner {
  background: linear-gradient(135deg, #ab2029, #D66765);
  border-radius: 0 0 24px 24px;
  padding: 20px 15px;
  color: #fff;
}
```

**规则：**
- 品牌红渐变背景，底部大圆角收口
- 白色文字：标题 24px bold、副标题 14px normal rgba(255,255,255,0.85)
- 可放置搜索栏（白色半透明底、圆角 16px）
- 此区域为品牌色的主要展示位

### 6.3 AI 智能摘要横幅

```css
.ai-summary-banner {
  background: var(--color-card); /* #ffffff */
  border-radius: 12px;
  padding: 12px 15px;
  border: 1px solid var(--color-divider);
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.04);
}
```

**规则：**
- 白色卡片背景，不使用紫色背景或紫色左侧竖线
- 多行紧凑布局：
  - 主行："今日8项待办，预计总耗时 3.5小时"
  - 子类别行："上午优先处理 高价值到期客户"
  - 子类别行："下午集中 联络超期客户"
  - 右侧："昨日回顾"按钮（圆形箭头图标 + 品牌红文字）
- 不使用 AI 头像圆形图标（移除 `.ai-avatar`）
- 关键数字加粗（8项、3.5小时）
- 子类别使用高亮色块标签（浅红/浅蓝底）
- 整个卡片可点击，展开 AI 排程详情浮层

### 6.4 卡片 Card

```css
.card {
  background: #ffffff;
  border-radius: 12px;
  padding: 16px;
  box-shadow: 0 2px 8px rgba(0, 0, 0, 0.04);
}
```

**规则：**
- 圆角统一 12px（`--radius-md`）
- 投影轻量：`0 2px 8px rgba(0, 0, 0, 0.04)`
- 可点击卡片：按下时 `scale(0.98)` + 投影减弱，150ms
- 卡片之间间距 10px（对齐 xlsx 模块间距）

### 6.5 按钮 Button

| 类型 | 场景 | 样式 |
|------|------|------|
| 主按钮 `.btn--primary` | 主要操作（开始处理、确认） | `#ab2029` 底 + 白色文字，圆角 20px |
| CTA按钮 `.btn--cta` | 引导行动 | `#F59E0B` 橙色底 + 白色文字，圆角 12px |
| 幽灵按钮 `.btn--ghost` | 次要操作 | 透明底 + `#ab2029` 文字 |
| 描边按钮 `.btn--outline` | 查看类操作 | 透明底 + `#999` 文字 + `#d5d5d5` 边框 |

**尺寸：**

| Size | 高度 | 内边距 | 字号 | 圆角 |
|------|:---:|------|------|------|
| `sm` | 32px | 0 16px | 13px | 8px |
| `md` | 40px | 0 20px | 15px | 20px（胶囊） |
| `lg` | 48px | 0 24px | 16px | 20px（胶囊） |

**规则：**
- 主按钮使用品牌红 #ab2029，圆角 20px 胶囊形
- CTA 按钮使用橙色，与主按钮形成对比
- 按下时缩放 + 颜色加深，150ms
- 禁用态 `opacity: 0.4`

## 七、交互规范

### 7.1 点击反馈

| 元素 | 反馈方式 |
|------|---------|
| 卡片（可点击） | `scale(0.98)` + 投影减弱，150ms |
| 主按钮 | `scale(0.96)` + 颜色加深，150ms |
| CTA 按钮 | `scale(0.96)` + 颜色加深，150ms |
| 列表行 | 背景变灰，150ms |
| 图标按钮 | 背景变灰，150ms |
| 快捷入口 | 背景变灰，150ms |
| Tab 切换 | 颜色切换，150ms（无缩放） |

**规则：** 所有可交互元素必须有视觉反馈，反馈时间 <=150ms。

### 7.2 手势

| 手势 | 场景 |
|------|------|
| 点击 | 主要操作 |
| 左滑 | 列表项快捷操作（查看客户画像/生成作战包） |
| 右滑 | 关闭已展开的左滑操作 |
| 下拉 | 工作台首页刷新（scrollTop=0 时） |
| 上滑 | 页面内滚动 |

### 7.3 动效时长

| 类型 | 时长 | 缓动 |
|------|:---:|------|
| 点击反馈 | 150ms | 0.3s ease |
| 页面过渡 | 250ms | 0.3s ease |
| 进度条动画 | 350ms | 0.3s ease |
| Toast 显隐 | 250ms | 0.3s ease |
| 按钮状态切换 | 300ms | 0.3s ease |

### 7.4 空状态

| 场景 | 处理方式 |
|------|---------|
| 待办为 0 条 | 不展示该类型（整行隐藏） |
| 列表为空 | 居中插图 + "暂无数据" + 操作引导 |
| 搜索无结果 | "未找到相关结果，试试其他关键词" |

## 八、页面布局规范

### 8.1 通用页面骨架

```
|--- 375px ---|
| Status Bar (24px)
| Header (auto, 白底 + 1px 分割线)
| Scroll Content (flex: 1, overflow-y: auto)
|   padding: 10px 15px
|   gap: 10px
| Tab Bar (56px + safe-area)
```

### 8.2 安全区域

- 设计基准宽度：375px
- 底部 Tab Bar 需适配 `safe-area-inset-bottom`
- 左右不留安全区（375px 全宽使用，内容 padding 15px）

### 8.3 触控最小区域

- 所有可点击元素的最小触控区域：44x44px
- 列表项高度 >=44px
- 按钮最小高度：32px（sm）/ 40px（md）/ 48px（lg）

### 8.4 底部导航（Tab Bar）

4-Tab 结构：
```
🏠 工作台 | 👥 客户 | 📦 产品 | 👤 我的
```
**参考实现：全部使用 SVG `<use href="#ico-xxx">` 图标，详见 workbench.html 及 `prototype/icons/` 目录。**

- 高度：56px + safe-area-inset-bottom
- 背景：白色，顶部 1px 分割线
- Tab 文字：9px normal #999（active：#ab2029）
- 选中态：文字变品牌红 + 顶部 2.5px 红色指示条
- Tab 图标：22px SVG图标（通过 `<use href="#ico-xxx"/>` 引用，动态主题切换）

## 九、图标系统

已从 Emoji 方案全面升级为 SVG Sprite 图标系统，支持多主题切换。

### 9.1 技术架构

- SVG Sprite 容器：`<svg id="iconSprite"><defs>...</defs></svg>`
- 图标引用方式：`<svg class="ico ico--md"><use href="#ico-xxx"/></svg>`
- 主题管理器：`window.IconManager`（`prototype/icons/icons.js`）
- 经典主题：`prototype/icons/icons-classic.js`（59个精修图标，统一 24x24 viewBox、stroke-width 2）
- 现代主题：`prototype/icons/icons-modern.js`（59个现代几何风格图标，默认主题）
- 主题持久化：`localStorage` key `yh_icon_theme`
- 切换入口：我的 → 设置 → 图标主题

### 9.2 图标尺寸

2
作战包 Battle Package
电话版 / 面谈版 · 客户概览+营销线索+话术脚本+产品推荐

❌ 待办不能直接创建作战包

✅ 商机是作战包的唯一来源

✅ 生成作战包时必须创建商机待办

🔄 全链路：来源 → 商机 → 作战包 → 商机待办 → 执行 → 回写

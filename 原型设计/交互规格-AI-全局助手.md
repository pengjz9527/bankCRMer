# 交互规格 — AI 助手全局交互

> **定位**：AI 助手在全局范围内的交互入口、对话浮层、能力清单、上下文感知和智能推送的完整规格。覆盖 FAB 悬浮按钮、AI 对话浮层、全局搜索 AI 增强、以及 AI 在各页面中的嵌入交互点。
>
> **前置依赖**：前五步全部交互规格（已定义各页面中的 AI 触点）、design-system-spec.md（AI 专属配色和动效规范）
>
> **设计原则**：
> - AI 是"主动服务"而非"被动工具"——先于客户经理发现问题、给出建议
> - AI 感知上下文——知道客户经理在哪一页、在看什么、需要什么
> - AI 可被随时呼出——FAB 按钮全局悬浮，不打断当前操作
>
> **版本**：v1.0 | **最后更新**：2026-07-15

## 一、AI 能力全景

### 1.1 AI 能力清单

```
AI 能力矩阵
├── 感知层（自动运行，无需触发）
│   ├── 智能排程：每日 T+1 推送排程建议
│   ├── 商机识别：系统推送 + AI 挖掘双通道
│   ├── 客户洞察：行为变化监测 + 主动推送
│   ├── 风险预警：流失概率 / 大额异动 / 到期提醒
│   └── 资讯摘要：每日金融资讯 AI 解读
│
├── 交互层（用户触发）
│   ├── AI 对话：FAB 按钮 → 自然语言问答
│   ├── 作战包生成：W3 商机 → [生成作战包]
│   ├── 话术生成：面谈中即时生成话术
│   ├── 偏离应对：P2/P3 偏离预制 + 实时调整
│   ├── 智能搜索：全局搜索 AI 增强
│   └── 新客推荐：Block 4 → AI 新客名单
│
└── 回顾层（周期性）
    ├── 昨日回顾：AI 生成每日工作总结
    ├── 周报生成：每周商机/待办/业绩汇总
    └── 策略建议：基于管户画像的季度策略
```

## 二、FAB 悬浮 AI 按钮

### 2.1 位置与视觉

```
┌──────────────────────────────────────────┐
│                                          │
│  （页面内容区）                           │
│                                          │
│                                    ┌───┐ │
│                                    │ ✨ │ │  ← FAB
│                                    └───┘ │
│                              [Tab Bar]   │
└──────────────────────────────────────────┘

定位：右下角，距右 16px，距 Tab Bar 上缘 -18px（半浮于 Tab Bar 上方）
尺寸：48×48px 圆形
背景：AI 渐变（#7C6FF0 → #6C5CE7）
投影：0 4px 16px rgba(108,92,231,0.45) + 外圈 3px 白色描边
动效：2.5s 周期呼吸脉冲（fab-pulse）
按下：scale(0.92) + 投影减弱
```

### 2.2 显示规则

| 场景 | FAB 行为 |
|------|------|
| W1 首页 | 始终显示，脉冲动效 |
| W2-W9 子页面 | 始终显示（返回按钮左侧无冲突） |
| P1-P9 面谈流程 | **隐藏**（面谈中不分散注意力） |
| AI 对话浮层已打开 | **隐藏**（避免重复触发） |
| 滚动页面时 | 保持固定位置 |

### 2.3 点击行为

| 当前页面 | 点击 FAB 行为 |
|------|------|
| W1 首页 | 弹出 AI 对话浮层，默认上下文 = "工作台概览" |
| W2 日程 | 弹出 AI 对话浮层，默认上下文 = "今日日程" |
| W3 商机 | 弹出 AI 对话浮层，默认上下文 = "商机管理" |
| W4-W9 | 弹出 AI 对话浮层，默认上下文 = 当前页面名称 |
| 全局搜索 | 弹出 AI 对话浮层，默认聚焦搜索输入 |

### 3.2 浮层动画

| 阶段 | 动画 |
|------|------|
| 打开 | 从 FAB 位置放大展开至全屏 90%（300ms，ease-out） |
| 关闭 | 缩小回 FAB 位置（250ms，ease-in） |

## 四、AI 对话——语音输入

### 4.1 触发方式

- 输入区 [🎤] 按钮：长按录音，松开发送
- 语音自动转文字 + AI 理解

### 4.2 交互

```
按下 [🎤] → 录音中状态：
┌──────────────────────────────────────────┐
│               🎙️ 正在聆听...              │
│          ▓▓▓▓▓▓▓░░░░░░░░░░░            │
│          松开按钮发送 · 上滑取消           │
└──────────────────────────────────────────┘
```

| 操作 | 行为 |
|------|------|
| 按住 [🎤] | 开始录音，震动反馈，波形动画 |
| 松手 | 停止录音 → 语音转文字 → 填入输入框 → 自动发送 |
| 上滑 | 取消录音（不发送） |
| 录音超时（60s） | 自动停止并发送 |

## 五、全局搜索 AI 增强

### 5.1 搜索入口

| 入口 | 说明 |
|------|------|
| Header 🔍 | 全局搜索页（全屏） |
| AI 对话浮层中自然语言 | "帮我查一下XX" → AI 理解意图并搜索 |

### 5.2 AI 增强搜索能力

区别于普通关键词搜索，AI 增强搜索理解**自然语言意图**：

| 用户输入 | 普通搜索 | AI 增强搜索 |
|------|------|------|
| "王建国" | 匹配客户姓名 | 匹配 + 展示画像摘要 + 最近交互 |
| "快到期了" | 无结果 | 理解意图 → 列出所有即将到期的客户和产品 |
| "上个月买了基金的客户" | 无结果 | 语义理解 → 筛选上月购买基金的管户客户 |
| "哪个理财收益高又安全" | 无结果 | 理解意图 → 列出 R1-R2 高收益产品 |
| "帮我看看谁最近没联系" | 无结果 | 理解意图 → 列出超期未联络客户 |

### 5.3 AI 搜索结果的展示

```
普通搜索：结果列表 + 分 Tab
AI 增强：结果列表 + 🤖 "AI 理解你可能想找..." + 智能建议卡片
```

## 九、AI 对话——高级能力

### 9.1 多轮对话上下文

AI 记住当前对话的上下文，支持连续追问：

```
用户："帮我看看王建国"
AI："王建国，财富客户，AUM 58.7万，定存25万即将到期。"
用户："给他推荐什么产品好？"
AI：（理解"他"=王建国）"建议推荐 XX 悦享周期理财 R2..."
用户："生成作战包"
AI：（理解上下文=王建国+XX理财）→ 确认弹窗 → 跳转 P1
```

上下文的生命周期：
- 同一次浮层打开期间有效
- 关闭浮层 → 上下文清除
- 可从其他页面带入初始上下文（见 3.3）

### 9.2 结构化数据展示

当 AI 回复涉及数据时，使用嵌入卡片而非纯文本：

```
┌──────────────────────────────────┐
│ 🤖                               │
│ 王建国 · 财富客户                 │
│ ┌──────────────────────────────┐ │
│ │ AUM 58.7万 │ 风险 R2 │ 稳健型 │ │  ← 数据卡片
│ │ 持有：定存25万 理财10万       │ │
│ │ 商机：定存到期承接            │ │
│ └──────────────────────────────┘ │
│ 建议操作：                       │
│ [生成作战包] [拨号] [查看详情]   │
└──────────────────────────────────┘
```

### 9.3 主动建议

当 AI 检测到可执行的操作时，主动提供快捷按钮：

| 检测场景 | 主动建议按钮 |
|------|------|
| 提到客户 + 商机 | [生成作战包] |
| 提到客户 + 电话 | [拨号] |
| 提到到期产品 | [查看详情] [推荐替代] |
| 提到业绩落后 | [分析原因] [提升建议] |
| 日程过密 | [AI 优化排程] |

## 十、AI 错误处理与兜底

### 10.1 错误类型

| 错误类型 | 展示 | 用户操作 |
|------|------|------|
| 网络超时（>10s） | "AI 响应较慢，请稍候..." + 加载动画 | 等待或 [取消] |
| 服务不可用 | "AI 服务暂不可用，请稍后重试" + [重试] | [重试] |
| 意图不明确 | "抱歉，我不太确定你想了解什么。可以换个方式描述吗？" | 重新输入 |
| 数据不可得 | "抱歉，暂时无法获取该数据" + 原因说明 | 提供替代方案 |
| 语音识别失败 | "未识别到语音内容，请重试或使用文字输入" | 重试 / 文字输入 |

### 10.2 兜底策略

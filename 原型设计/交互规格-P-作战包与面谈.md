# 交互规格 — P 作战包与面谈流程

> **定位**：P1-P9 作战包与面谈流程的完整交互规格。覆盖从"生成作战包"到"面谈结束回写商机状态"的全链路交互。
>
> **前置依赖**：W3 商机管理页（定义作战包生成入口契约）、核心业务设计模型（商机→作战包→商机待办链路）、面谈中交互流程设计.md（流程骨架）
>
> **页面范围**：P1 作战包首页 → P2 面谈主界面 → P3-P9 子页面/浮层
>
> **版本**：v1.0 | **最后更新**：2026-07-15

---

## 一、整体流程与状态机

### 1.1 入口来源

| 来源 | 触发 | 跳转目标 |
|------|------|------|
| W3 商机管理页 [生成作战包] | 选择模式后 | P1 作战包首页 |
| Block 2 商机待办卡片 [查看作战包] | 直接点击 | P1 作战包首页（已生成过的作战包） |

### 1.2 全局状态机

```
P1(作战包首页) → P2(面谈主界面) ⇄ P3/P4/P5/P6/P8(子页面)
                                    │
                                    ▼ [结束面谈]
                              P7(面谈结束页) ⇄ P9(客户确认要点)
                                    │
                                    ▼ [返回工作台]
                              商机状态回写 + 商机待办完成
```

### 1.3 面谈中全局状态

| 状态字段 | 初始值 | 变更时机 |
|------|------|------|
| 面谈计时器 | 00:00 | P1 [开始面谈] → 开始计时；P7 确认结束 → 停止 |
| 顶部状态栏 | 无 | P2 进入 → 🟢 "面谈中 · 已进行 mm:ss · 客户名" |
| 作战包版本 | 锁定 | P1 [开始面谈] → 锁定，面谈中不再自动更新 |
| 线索状态 | 3 条未开始 | 逐条执行/完成/跳过时更新 |

## 二、P1 作战包首页

### 2.1 页面入口与数据契约

**从 W3 传入的数据**（见 W3 商机管理 6.2 节）：

| 字段 | 用途 |
|------|------|
| 商机 ID | 关联回写 |
| 客户 ID | 拉取客户画像 |
| 作战包模式 | 电话版 / 面谈版 |
| 商机类型 | 影响作战包内的线索方向 |

### 2.2 电话版 vs 面谈版差异

| 维度 | 电话版（轻量） | 面谈版（全功能） |
|------|------|------|
| 线索数量 | 1 条（核心话题） | 1-3 条（议程式） |
| 偏离预制 | 无（电话场景不需要偏离分支） | 每条线索 3-5 个偏离分支 |
| 面谈议程 | 无 | 有（含时间分配建议） |
| 底部按钮 | [拨号联系] [查看画像] [返回] | [开始面谈] [编辑] [返回] |
| 顶部状态 | 无计时（电话场景） | 开始计时 |

### 2.3 作战包内容结构（面谈版）

```

├──────────────────────────────────────────┤
│                                          │
│ 1. 客户全景速览                   [展开▼] │
│    王建国 · 财富 · 稳健型 · AUM 58.7万     │
│    🔴 定存到期 🟡 基金偏好 🟢 教育金      │

│ 2. 营销线索清单 (3条)                     │

│ │ 💬 切入话术（可复制）                 │ │
│ │ 📦 推荐产品 ×3（可点击查看详情）       │ │
│ │ 💡 偏离预制 5 个分支                  │ │
│ └──────────────────────────────────────┘ │
│ ┌──────────────────────────────────────┐ │
│ │ 🟡 线索 #2：基金偏好挖掘     [展开▼]  │ │
│ └──────────────────────────────────────┘ │

│                                          │
│ [开始面谈]                               │
└──────────────────────────────────────────┘
```

### 2.4 P1 交互行为

| 触发 | 行为 |
|------|------|
| [开始面谈] | 确认弹窗 → APP 进入面谈中状态 → 跳转 P2，默认展示第一条线索 → 开始计时 |
| [编辑] | 进入编辑模式：可增删线索、替换产品、修改话术 |
| 点击产品卡片 | 展开产品详情（四宫格） |
| [复制] 话术 | 复制到剪贴板 → Toast "已复制" |
| 展开偏离分支 | 预览偏离话术和策略 |
| [返回] | 确认弹窗（`尚未开始面谈，确定返回？`）→ 回到 W3 或工作台 |

### 2.5 P1 状态

| 状态 | 展示 |
|------|------|
| 加载中 | 骨架屏：标题 + 3 个卡片占位 |
| 生成失败 | "作战包生成失败，请重试" + [重新生成] |
| 正常 | 完整作战包内容 |
| 编辑中 | 可拖拽排序线索、删除/添加产品 |

## 三、P2 面谈主界面

```

│                                          │
│ 💬 切入话术                              │  ← 主剧本区
│ "王先生您好，您有一笔25万定存..."         │
│ [复制] [切换风格]                         │
│                                          │
│ 📦 推荐产品 (3只)                         │  ← 产品区
│ [XX理财 3.8%] [YY悦享 4.1%] [ZZ现金 2.5%] │

```

### 3.2 线索导航栏

| 操作 | 行为 |
|------|------|
| [←] / [→] | 切换到上一条/下一条线索 |
| 点击标题 | 弹出 P5 线索切换面板 |
| 线索全部完成 | 导航栏显示 "✅ 全部线索已完成" |

### 3.3 主剧本区交互

| 触发 | 行为 |
|------|------|
| [复制] 话术 | 复制到剪贴板，Toast "已复制" |
| [切换风格] | 口语化 ↔ 专业化切换，即时渲染 |
| 点击产品卡片 | 展开产品详情小面板（不离开 P2） |
| [👁 展示模式] | 跳转 P4，将当前线索的推荐产品以展示模式呈现 |

### 3.4 偏离预制区交互

| 触发 | 行为 |
|------|------|
| 点击预制偏离选项 | 跳转 P3 偏离详情卡片（半屏浮层，从底部滑入） |
| 点击"以上都不匹配" | 弹出 P8 兜底搜索界面 |

### 3.5 底部操作栏

| 按钮 | 行为 | 跳转 |
|------|------|------|
| [🔒私密] | 当前为私密模式，点击无效果 | — |
| [👁展示] | 切换到展示模式 | P4 |
| [📝记录] | 弹出快速记录浮层 | P6 |
| [📋线索] | 弹出线索切换面板 | P5 |
| [⏹结束] | 确认弹窗 → 结束面谈 | P7 |

### 3.6 P2 状态

| 状态 | 展示 |
|------|------|
| 正常面谈中 | 完整界面，计时器运行 |
| 线索切换中 | 主剧本区内容过渡动画（300ms 淡入淡出） |
| 全部线索完成 | 导航栏显示完成提示，[⏹结束] 按钮高亮 |
| 面谈超时提醒 | 超过议程建议时间 5 分钟 → 顶部黄色提示条 "面谈已超时，建议收尾" |

### 8.3 跟进任务的类型

> **设计约束**：P7 创建的跟进任务为**普通待办**，不关联商机。它们只是提醒（如"3 天后联系确认"），不携带作战包。如果面谈中发现了新商机，应在 P6 中标记 [新需求]。

### 8.4 完成后的系统动作

| 动作 | 说明 |
|------|------|
| 商机待办标记完成 | 当前关联的商机待办 → "已完成" |
| 商机状态回写 | 商机状态：已生成作战包 → 已触达，待结果 |
| 跟进任务创建 | 生成 1-N 条普通待办，加入待办清单 |
| 客户标签更新 | 写入客户画像 |
| 偏离场景入库 | 新偏离分支保存到预制库，下次作战包自动包含 |
| 面谈记录保存 | 写入 W7 面谈回顾 |

### 8.5 返回目标

| 操作 | 跳转目标 |
|------|------|
| [返回工作台] | W1 首页，Block 2 数据刷新（商机待办已移除） |
| [查看画像] | 客户画像页（含最新面谈记录） |

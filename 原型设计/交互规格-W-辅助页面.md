# 交互规格 — W 辅助页面集

> **定位**：Block 4 新客拓展推荐的深度交互 + W4-W9 辅助页面的完整设计。覆盖工作台之外的六个独立页面、Tab Bar 三个入口页面，以及来自 Header 的消息通知。
>
> **前置依赖**：W1 首页交互规格（已定义 Block 4 展示层和跳转映射）、核心业务设计模型（商机三来源、客户经理创建商机入口）
>
> **页面范围**：
> - Block 4 新客拓展推荐（首页内深度交互 + 条件显示逻辑）
> - W4 业绩看板（全屏独立页面）
> - W5 每日资讯（全屏独立页面）
> - W6 昨日回顾（全屏独立页面）
> - W7 面谈记录（全屏独立页面）
> - W8 我的客户（全屏独立页面）
> - W9 日程管理（全屏独立页面）
> - 消息通知列表（浮层/独立页面）
> - 产品搜索页（Tab Bar 入口）
> - 个人中心（Tab Bar 入口）
>
> **版本**：v1.0 | **最后更新**：2026-07-15

## 一、模块总览

```
Block 4 新客拓展推荐（首页内）
├── 显示逻辑：商机挖潜触达上限 → 条件显示
├── 内容：推荐文本 + 缺口提示
├── [获取 AI 推荐新客名单] → W8 我的客户（新客筛选模式）
└── 状态：正常 / 已满足（隐藏） / 加载中

W4 业绩看板（独立页面）
├── AUM / 理财 / 基金 三项指标
├── 时间维度：本月 / 本季 / 本年
└── 进度可视化 + 同比/环比

W5 每日资讯（独立页面）
├── 金融资讯流 + AI 摘要
└── 分享 / 收藏

W6 昨日回顾（独立页面）
├── AI 生成昨日工作总结
└── 待办完成情况 + 商机推进

W7 面谈记录（独立页面）
├── 历次面谈列表 + 筛选
└── 面谈详情（作战包 + 偏离记录 + 结果）

W8 我的客户（独立页面）
├── 客户列表 + 搜索 + 筛选
├── 客户画像详情
└── 新客筛选模式（从 Block 4 入口）

W9 日程管理（独立页面）
├── 日历视图（月/周/日）
├── 历史日程 + 未来预览
└── 手动添加日程

Tab Bar 辅助入口
├── 产品搜索页
└── 个人中心

Header 入口
└── 消息通知列表
```

## 二、Block 4 新客拓展推荐——深度交互

### 2.1 显示逻辑

```
商机挖潜状态判断：
  当前商机数 + AI 可挖掘数 ≥ 目标所需商机数 × 1.2
  ├── 是 → Block 4 隐藏（当前商机储备充足）
  └── 否 → Block 4 显示（建议拓展新客源）
```

| 显示条件 | Block 4 行为 |
|------|------|
| 商机储备充足（≥120% 目标所需） | 整块隐藏，不占空间 |
| 商机储备不足（< 120% 目标所需） | 正常显示，提示拓展 |
| 缺口严重（< 80% 目标所需） | 显示 + 橙色警告样式 |

### 2.2 卡片结构

```
┌──────────────────────────────────────────┐
│ 💡 新客拓展推荐                           │
│                                          │
│ 当前管户 238 位客户中，可挖掘商机已近      │
│ 上限。如需持续完成季度目标，建议拓展新客源。 │
│ AI 推荐新增 50 户目标客群。               │
│                                          │
│ [📋 获取 AI 推荐新客名单]                  │
└──────────────────────────────────────────┘
```

### 2.3 交互行为

| 触发 | 行为 |
|------|------|
| [获取 AI 推荐新客名单] | 跳转 W8 我的客户页面，自动切换为「新客筛选」模式 |
| 卡片整体点击 | 同上（整卡热区） |

### 2.4 Block 4 状态

| 状态 | 展示 |
|------|------|
| 正常显示 | 完整卡片内容 |
| 警告显示 | 卡片 + 橙色边框 + "商机缺口较大"提示 |
| 已满足（隐藏） | 整块不渲染 |
| 加载中 | 骨架屏（单行横条） |

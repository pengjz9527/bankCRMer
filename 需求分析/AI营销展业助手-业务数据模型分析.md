> ⚠️ **设计约束**：本文档中待办、商机、作战包的定义和关系，以《核心业务设计模型-待办商机作战包.md》为权威依据。

---

## 一、项目定位

徽商银行"易知客"系统内嵌智能助手（品牌名"易会办"），以金融大模型为核心，采用**对话式交互**，赋能一线客户经理实现：

- 从"被动响应客户需求" → "主动经营客户价值"
- 从"个人经验驱动" → "数据+AI双轮驱动"

## 三、核心业务对象及数据结构

### 3.1 客户 `Customer`

#### 搜索/筛选条件

| 字段 | 匹配方式 | 说明 |
|------|---------|------|
| 手机号 | 精确 | — |
| 姓名 | 模糊 | — |
| 客户号 | 精确 | — |
| 证件号 | 精确 | — |
| 客群 | 筛选 | 从已有客群中圈选 |
| 持有产品 | 多选筛选 | 理财/基金/消费贷/经营贷/房贷 |

#### 列表展示字段

```
姓名 | 客户号 | 手机号(掩码) | 年龄 | 性别 | 职业
```

#### 客户等级体系

| 等级 | 资产范围 |
|------|---------|
| 千元以下 | < 1,000 |
| 千元户 | 1,000 ~ 1万 |
| 万元户 | 1万 ~ 5万 |
| 优质 | 5万 ~ 20万 |
| 财富 | 20万 ~ 100万 |
| 高净值 | 100万 ~ 300万 |
| 私钻 | 300万 ~ 600万 |
| 私行 | 600万+ |

#### 客户投资周期偏好枚举

| 偏好类型 | 时间范围 |
|---------|---------|
| 短期 | 0 ~ 1个月 |
| 中短期 | 1 ~ 3个月 |
| 中期 | 3个月 ~ 1年 |
| 长期 | 1年以上 |

#### 客群保存规则

- 最多保存前 10,000 名客户
- 超出自动截断
- 保存至易知客系统，需填写业务类型和营销目的
- 成功/失败以 TOAST 提示

### 3.3 理财产品 `WealthProduct`

#### 搜索筛选条件

| 维度 | 可选值 |
|------|--------|
| 产品类型 | 活钱理财 / 按日开放 / 固定周期 / 定期开放 / 悦享周期 / 明星产品 / 私募尊享 / 专属理财 / 夜市理财 / 外币理财 |
| 投资期限 | 无固定期限 / 灵活期限 / 定期开放 / 固定期限 |
| 收益率 | <0% / 0%~1% / 1%~2% / ≥3% |
| 风险等级 | R1(低) / R2(中低) / R3(中) / R4(中高) / R5(高) |
| 币种 | 人民币 / 美元 / ... |
| 管理机构 | 徽银 / 兴银 / 杭银 / 南银 / 平安 / 苏银 / 中银 / 信银 / 中邮理财 / 渤银 ... |
| 募集方式 | 私募 / 公募 |

#### 产品模板与收益率展示规则

| 模板代码 | 含义 | 展示收益率逻辑 |
|----------|------|----------------|
| D310 | 现金管理类 | 募集期→业绩比较基准；开放期→近七日年化 |
| D300 | 日开 | 成立<1月→业绩比较基准；1~6月→成立以来年化；≥6月→近半年年化 |
| D306 | 客户周期 | 同 D300 |
| D301/D309 | 定开 | 同 D300 |
| D303 | 封闭 | 业绩比较基准 |

#### 投资期限分类规则

| 类型 | 判定规则 |
|------|---------|
| 无固定期限 | 产品模板为 D300, D306 |
| 定期开放 | 产品模板为 D301, D309 |
| 固定期限 | TransWay=2（封闭式） |
| 灵活期限 | 其余所有产品 |

#### 小卡（列表卡片）

```
产品名称 | 风险等级 | 展示收益率 | 标签(产品规则) | 起购金额 | 收益率解释说明
```

- **活钱理财**（PrdSerial=0）：产品名称/风险等级/收益率/标签/收益率说明
- **按日开放/定期开放/固定期限/悦享周期/其他**：产品名称/风险等级/收益率/标签/起购金额/收益率说明

    │   ├── 产品币种
    │   ├── 风险等级

### 3.6 产品对比 `ProductCompare`

#### 理财产品对比维度

| 层级 | 内容 |
|------|------|
| 一句话总结 | LLM 生成，≤200字 |
| 核心对比 | 产品名称、产品代码、类型标签、展示收益、风险等级、流动性、销售状态、业绩比较基准(默认收起) |
| 扩展对比 | 基础信息、交易规则(LLM总结≤100字)、投资方向(LLM总结≤100字)、历史业绩图表、产品分析(LLM总结≤200字) |

历史业绩展示分三种情况：
- 2只都是现金类：七日年化+万份收益 2条曲线
- 2只都是非现金类：区间涨跌幅对比列表
- 1只现金+1只非现金：分别展示各自详情

#### 基金产品对比维度

| 层级 | 内容 |
|------|------|
| 一句话总结 | LLM 生成，≤200字 |
| 核心对比 | 产品名称、产品代码、类型标签、日涨幅、风险等级 |
| 扩展对比 | 基础信息、历史业绩(LLM总结≤100字)、基金持仓(LLM总结≤100字)、基金经理(LLM评价)、交易规则(LLM总结≤100字)、产品分析(LLM总结≤100字) |

历史业绩展示分三种情况：
- 2只都是货币型：七日年化+万份收益 2条曲线
- 2只都是非货币型：区间收益率对比列表（含同类平均、同类排名）
- 1只货币+1只非货币：分别展示各自详情

#### 保险产品对比维度

```
产品名称 | 产品属性 | 缴费年期类型 | 缴费期间 | 保障年期类型 | 保险期间 | 风险等级
```

### 3.7 待办 `Task`

> **设计约束**：待办的完整分类、与商机/作战包的关系，以《核心业务设计模型-待办商机作战包.md》为准。此处仅定义数据字段。

待办分为两大类：**普通待办** 和 **商机待办**。

#### 3.7.1 公共基础字段（所有待办共用）

```
待办ID | 类型(普通/商机) | 客户姓名 | 年龄 | 性别 | 职业 | 客户号 | 建议时段 | 预计耗时
```

#### 3.7.2 普通待办（六类，系统推送）

**本质**：执行动作。处理即结束，不关联商机，不生成作战包。

| 类型 | 特有字段 | 处理按钮 | 排序规则 | 可选携带作战包 |
|------|---------|:---:|------|:---:|
| **产品到期** | 产品名称、金额、到期日期 | ✅ | 按到期日 | ❌ |
| **大额异动** | 当前余额、上日异动金额(+红色/-绿色) | ✅ | — | ❌ |
| **贷款逾期** | 产品名称、逾期金额、逾期次数、还款日期 | ✅ | 按待办下发日期 | ❌ |
| **生日提醒** | 出生日期、距离生日还有X天 | ✅ | 按生日日期 | ❌ |
| **联络超期** | 总资产余额、最后联络日期、超期天数 | ❌ | T+1数据表，按数据日期 | ❌ |
| **信用卡待办** | 信用卡账号、业务类型 | ✅ | 按数据更新日期 | ❌ |

> 普通待办包含事务性工作（生日提醒、信用卡通知）和触达类工作（联络超期），不再区分。

#### 3.7.3 商机待办（商机生成作战包时强制创建）

**本质**：执行动作 + 携带作战包。必须关联商机，完成后回写商机状态。

| 字段 | 说明 |
|------|------|
| 关联商机ID | 必填，可追溯 |
| 标题 | 格式："拜访客户 · XXX" |
| 拜访方式 | 电话 或 线下面谈 |
| 携带作战包ID | 必填，1:1 绑定 |
| 建议时段 | AI 根据日程自动排程 |
| 预计耗时 | AI 估算 |

**执行后回写规则**：
- 商机待办完成 → 商机状态更新为"已触达，待结果"
- 作战包过期未使用 → 商机状态回退为"待跟进"

#### 信用卡业务类型枚举

```
信用卡年费收取 | 信用金到期 | 信用金提前还款 | 信用卡降级 | 信用卡逾期
```

#### 任务交互

- **处理按钮**：点击后处理成功→翻转为"已处理"；处理失败→TOAST提示"处理失败，请稍后再试"
- **左滑快捷操作**：普通待办 → [标记为商机]；商机待办 → [查看作战包]
- **每日推送**：
  - T-1日待办完成率
  - 昨日工作总结（智能中枢生成）
- **自然语言查询**：支持意图识别匹配（见 3.10 意图识别表）

### 3.8 商机 `Opportunity`

> **设计约束**：商机是作战包的**唯一生成源**。商机≠待办，商机是"机会"，待办是"行动"。

商机有三类来源：

#### 来源一：系统推送商机

后台系统基于明确规则识别并自动推送，不依赖大模型。

| 商机类型 | 推送系统 | 识别逻辑 | 关键字段 |
|------|------|------|------|
| 代发即将到账 | 数仓 → 代发流水 | 近6月有稳定代发 + 未来7天将到账 | 姓名、年龄、性别、职业、客户号、近6月月均代发金额、最近1次代发日期 |
| 流失预警 | 大数据平台 → 流失模型 | AUM下降 + 活跃度衰减 + 他行转账 | 姓名、年龄、性别、职业、客户号、资产金额、客户等级、流失概率 |
| 产品到期（大额） | 数仓 → 持仓数据 | 到期金额 ≥ 阈值 | 产品名称、金额、到期日 |

> **特征**：规则明确、字段固定、不依赖大模型。本质是"条件筛选 + 阈值判断"。
> **待扩展**：后续需细化补充可推送的商机类型清单。

#### 来源二：客户经理主动创建

客户经理在执行普通待办、触达客户过程中，基于真实对话发现新需求后手动标记或创建。

**创建入口**：
- 处理普通待办时 → "标记为商机"
- 面谈中 P6 快速记录 → 标签 [新需求]
- 面谈结束 P7 → "补充偏离场景"
- 工作台 → 手动添加入口

**关键字段**（由客户经理填写）：
```
客户姓名 | 客户号 | 商机类型(自填) | 预估金额 | 意向描述 | 发现渠道(电话/面谈/微信等) | 优先级
```

#### 来源三：AI 智能挖掘商机

AI 基于客户洞察、关系关联分析，结合大模型推理能力生成。**必须与来源一做严格区分**——如果只是规则筛选，不应归入此类。

| 能力 | 示例 | 关键字段 |
|------|------|------|
| 客户生命阶段推断 | 分析消费流水 → 识别"子女升学""退休临近"节点 | 客户号、商机类型、置信度、推理链路 |
| 关系图谱挖掘 | 同一企业代发客户 → 同事/上下级 → 转介绍可能 | 客户号、关联客户号、关系类型 |
| 行为序列预测 | 近3月频繁浏览基金频道 + 无持仓 → 基金购买意向 | 客户号、行为摘要、预测意向 |
| 跨产品关联 | 经营贷客户 + 无理财持仓 + 经营流水稳定 → 闲置资金理财 | 客户号、已持有产品、推荐方向 |

> **特征**：非确定性、带置信度、有推理链路可解释。推送时需附带"为什么这么判断"，与来源一的"命中规则"明确区分。

#### 商机公共字段

```
商机ID | 来源(系统推送/客户经理创建/AI挖掘) | 客户姓名 | 客户号 | 商机类型 | 预估价值 |
状态(待跟进/已生成作战包/已触达/已转化/已流失) | 创建时间 | 更新时间
```

#### 自然语言查询

支持意图识别匹配（见 3.10 意图识别表）

### 3.9 作战包 `BattlePackage`

**本质**：执行弹药。客户经理联系客户前的信息准备和能力支撑，是商机待办的资源配置。

> ⚠️ **关键约束**：作战包不能凭空产生，必须源于商机。待办不能生成作战包，只能**携带**作战包。

#### 生成规则

| 规则 | 说明 |
|------|------|
| 唯一来源 | 只能由商机生成（商机 → [生成作战包]） |
| 数量约束 | 一个商机只生成一个作战包（1:1） |
| 同步动作 | 生成作战包的同时，强制创建商机待办 |
| 商机待办绑定 | 生成的商机待办自动携带此作战包 |

#### 两种模式

| 模式 | 适用场景 | 核心内容 |
|------|------|------|
| **电话版（轻量）** | 电话拜访 | 客户速览、切入话术、推荐产品、风险提示 |
| **面谈版（全功能）** | 线下面谈 | 客户速览、议程线索、切入话术、推荐产品、偏离预案、风险提示 |

#### 核心数据结构

```
作战包
├── 作战包ID
├── 关联商机ID（必填，1:1）
├── 模式（电话版 / 面谈版）
├── 生成时间
├── 有效期（建议7天，过期未使用则商机状态回退）
│
├── 客户速览
│   ├── 基本信息摘要
│   ├── 资产概览
│   └── 本次拜访目的
│
├── 线索清单（面谈版多条，电话版1条）
│   └── 每条线索
│       ├── 线索标题
│       ├── 💬 切入话术
│       ├── 📦 推荐产品（≤3只）
│       ├── 🎯 产品话术
│       └── 💡 偏离预制分支（3-5个，仅面谈版）
│
├── 风险提示 / 合规提醒
└── 状态（未使用 / 已使用 / 已过期）
```

### 3.11 智能推荐 `Recommendation`

#### 产品推荐过滤规则

```
条件1: 产品风险等级 <= 客户风测等级
条件2: 产品在售
排序:  按收益率高低取 TOP3（待业务确认）
```

#### 展示规则

| 产品类别 | 推荐产品 | 明星产品 |
|---------|:---:|:---:|
| 理财 | ≤3只 | ≤3只 |
| 基金 | ≤3只 | ≤3只 |
| 存款 | ≤3只 | ≤3只 |

#### 异常场景处理

| 场景 | 展示内容 |
|------|---------|
| 客户未风测 | 提示"未风测" |
| 风测已过期 | 提示"风测已过期" |
| 风测有效 + 有推荐产品 | 推荐产品 + 明星产品 |
| 风测有效 + 无推荐产品 | 仅明星产品 |

### 3.12 话术 `Script`

#### 话术类型

| 类型 | 输入 | 生成依据 |
|------|------|---------|
| 开场白话术 | 客户 + NL | 客户画像（年龄/职业/城市/投资偏好/商机等） |
| 理财产品话术 | 产品 + NL | 产品卖点提炼 + 合规提示 |
| 基金产品话术 | 产品 + NL | 同上 |
| 保险产品话术 | 产品 + NL | 同上 |
| 存款产品话术 | 产品 + NL | 同上 |
| 权益话术 | 权益 + NL | 权益介绍/进阶门槛/稀缺性 |
| 活动话术 | 活动 + NL | 活动信息提炼 |

#### 话术风格

| 风格 | 说明 |
|------|------|
| 口语化（默认） | 自然、亲切的日常表达 |
| 专业化 | 正式、专业的金融表达 |

> 输出专业化话术后增加追问："如想转换话术风格，请这样说：生成口语化版本"  
> 输出口语化话术后无需追问

#### 澄清流程

- 未提及具体对象 → 弹出搜索卡片
- 搜索到多个对象 → 展示澄清列表（如"查询到X位客户，请确认是哪一位"）

## 一、见客户前（准备阶段）—— "访前透视镜"

> **场景画像**：明天上午约了王先生面谈，打开APP选择该客户，一键生成"访前作战包"。
> **核心产出物**：一套 **策略+线索+产品+话术** 的访前营销指导方案。
> **产品隐喻**：像"透视镜"一样穿透数据，让客户经理在见客户前就心中有数、手中有策。

### 心智模型：**"我要的不是一堆数据，是一套见面后可以直接用的作战方案"**

客户经理的内心独白：
1. "这个客户现在是什么情况？" → 快速回顾全景
2. "见面后我该跟他聊什么？从哪切入？" → 需要面谈议程
3. "哪些产品适合他？为什么适合？" → 需要推荐清单+理由
4. "怎么开口说？每个话题怎么说？" → 需要配套话术
5. "见完面之后要干什么？" → 需要后续行动建议

### 产出物：访前作战包 `PreVisitKit`

```
访前作战包
├── 1. 客户全景速览         ← "他是谁" 看完心里有底
├── 2. 营销线索清单         ← "聊什么" 按优先级排序的谈话要点
│   ├── 线索 #1: 定存到期承接
│   │   ├── 发现依据（为什么会有这个线索）
│   │   ├── 营销策略（这个线索怎么打）
│   │   ├── 切入版话术（怎么开口引出这个话题）
│   │   ├── 推荐产品列表（匹配的产品）
│   │   └── 产品介绍话术（每个产品怎么说）
│   ├── 线索 #2: 基金偏好挖掘
│   ├── 线索 #3: 教育金规划
│   └── ...
├── 3. 面谈议程建议         ← "按什么顺序聊"
├── 4. 风险提示与注意事项    ← "什么不能踩"
└── 5. 面谈后续行动建议      ← "聊完干什么"
```

### 核心使用路径

> **注意**：作战包由商机生成，而非待办直接生成。以下路径中，[生成访前作战包] 的前提是已存在关联该客户的商机。

```
从商机列表点击进入（或搜索客户 → 查看画像 → 关联商机）
        ↓
点击 [生成访前作战包]
        ↓ 同步创建商机待办 🟣
AI 自动整合以下数据源，输出结构化方案：
  ├── 客户画像数据（基础信息/财富/信贷/行为洞察）
  ├── 智能推荐引擎（产品/权益/活动推荐）
  ├── 商机信号（产品到期/大额异动/代发到账/流失预警）
  ├── 历史沟通记录（智能中枢总结）
  └── 市场行情/每日资讯
        ↓
输出「访前作战包」→ 客户经理审阅、调整、确认
        ↓
见客户
```

#### 2. 营销线索清单（核心产出物）

> **每个线索 = 一个可执行的面谈话题单元**，包含：发现依据 → 营销策略 → 切入话术 → 产品匹配 → 产品话术。
> **排序规则**：按优先级从高到低排列（紧急度 × 成交概率 × 预期价值）。

---

##### 线索 #1：定存到期承接 🔴 高优先

**发现依据**
> 王先生持有一笔 25 万元定期存款，将于 7月18日（3天后）到期。当前定存利率持续下行，到期后续存收益偏低。王先生行内客户等级为"财富"，风险测评结果为"稳健型"，具备配置中低风险理财产品的基础条件。

**营销策略**
> 以"定存到期提醒"为切入点，自然过渡到"资产保值增值"话题。核心策略：不流失这笔到期资金，引导客户将部分或全部到期资金配置到收益更高的理财产品。先解决"钱往哪放"的问题，再顺势挖掘是否有新增资金可以配置。

**切入话术**（口语化，可按原话念出）
> "王先生您好，今天约您来主要是想跟您聊一下，您有一笔25万的定存7月18号就到期了。最近定存利率一直在降，如果直接续存的话收益可能不太理想。我帮您提前看了几款理财，风险等级跟您之前的产品差不多，都是R2稳健型，但收益要好不少。您有时间的话我给您详细介绍一下？"

**推荐产品**
| 产品 | 类型 | 风险 | 展示收益 | 起购 | 推荐理由 |
|------|------|:---:|------|:---:|------|
| XX稳健增长A | 理财/定开 | R2 | 近半年年化 3.8% | 1万 | 收益高于定存，风险可控，适合稳健型客户 |
| YY悦享周期90天 | 理财/悦享 | R2 | 成立以来年化 4.1% | 1万 | 期限适中，流动性好，到期自动续期 |
| ZZ现金管理 | 理财/现金 | R1 | 近七日年化 2.5% | 1元 | 如果客户不想锁定期限，可先放现金管理类过渡 |

**产品话术**
> **XX稳健增长A**："这款产品最大的特点是稳，成立3年多了，历史业绩一直比较稳定。近半年年化做到了3.8%，比现在定存利率高出不少。而且每个月有开放日可以赎回，需要用钱也方便。"
>
> **YY悦享周期90天**："如果您觉得3个月能接受的话，这款悦享周期的收益更高一些，成立以来年化4.1%。每90天自动滚续，到期了不想继续也可以赎回。"

---

##### 线索 #2：基金偏好挖掘 🟡 中优先

**发现依据**
> 近30天王先生在手机银行高频浏览基金频道，累计访问23次。近180天浏览产品风险等级主要集中R3-R5区间，表明其对权益类产品有一定关注。当前行内持有基金18万元，占比约31%。其风测结果为"稳健型"，具备购买R3及以下基金产品的资格。

**营销策略**
> 以"注意到您最近在看基金"自然切入，先了解客户对基金的真实兴趣和认知水平，再推荐匹配的基金产品。注意：客户浏览R3-R5产品但不代表风险承受能力匹配，推荐时必须严格遵守"产品风险等级 ≤ 客户风测等级"的合规要求。

**切入话术**
> "王先生，我们系统显示您最近在手机银行上看了不少基金产品，是最近对基金投资比较感兴趣吗？有没有特别关注的方向？我可以帮您分析分析。"

**推荐产品**
| 产品 | 类型 | 风险 | 日涨幅 | 起购 | 推荐理由 |
|------|------|:---:|------|:---:|------|
| AA稳健混合 | 基金/混合 | R3 | +1.2% | 1000 | 符合风测，波动适中，适合首次尝试权益类 |
| BB债券增强 | 基金/债券 | R2 | +0.3% | 1000 | 风险更低，适合作为基金配置的第一步 |

**产品话术**
> **AA稳健混合**："这款是混合型基金，股债搭配，不会像纯股票基金那么大起大落。基金经理从业8年了，经历过牛熊市，历史业绩在同类里排名前30%。如果用定投的方式参与，还能进一步分散风险。"

---

##### 线索 #3：子女教育金规划 🟢 常规跟进

**发现依据**
> 客户画像显示"已婚、已育、子女处于基础教育阶段"。上次沟通记录中客户主动提到"孩子上初中了，费用不少"。该客户无教育金类保险或教育储蓄产品。

**营销策略**
> 从"上次您提到孩子教育"自然接续话题，以关心客户家庭需求的角度切入，推荐教育金保险或长期理财方案。注意节奏：先倾听客户的真实想法和预算，不要急于推销。

**切入话术**
> "王先生，上次听您提到孩子上初中了，现在教育费用确实不低。您有没有考虑过提前给孩子规划一笔教育金？现在存一点，将来上大学、出国都能用上，压力也小很多。"

**推荐产品**
| 产品 | 类型 | 风险 | 关键信息 | 起购 | 推荐理由 |
|------|------|:---:|------|:---:|------|
| CC金宝贝年金险 | 保险/寿险 | — | 缴费10年/保障至25岁 | 年缴1万起 | 专为教育设计，到期给付，确定性高 |
| DD长期定投组合 | 基金定投 | R3 | 月定投 | 1000/月 | 长期复利，灵活取用，适合教育金积累 |

**产品话术**
> **CC金宝贝年金险**："这款教育年金险是专为孩子教育设计的，您每年缴一笔，等孩子上大学、大学毕业的时候分阶段返回来，相当于强制储蓄加增值。确定性高，不受市场波动影响。"

#### 3. 面谈议程建议

> **目的**：告诉客户经理按什么顺序聊，先聊什么后聊什么，不是让客户经理僵硬执行，而是提供一个经过设计的节奏。

```
面谈议程（建议总时长：30-40分钟）

① 开场寒暄（2-3分钟）
   话题：上次沟通的延续 / 客户近期情况关心
   参考：开场白话术

② 核心议题：到期资金承接（10-15分钟）★ 必须聊
   对应：线索 #1
   目标：确认到期资金意向，推动理财配置
   准备：定存到期提醒切入 → 推荐产品展示 → 答疑 → 确认意向

③ 延伸议题：基金配置建议（5-10分钟）
   对应：线索 #2
   目标：了解客户基金投资兴趣，介绍入门产品
   准备：以浏览行为切入 → 了解真实需求 → 推荐匹配基金
   注意：如果客户对基金没兴趣，不要强推，跳到下一个

④ 关怀议题：子女教育规划（5-10分钟）
   对应：线索 #3
   目标：唤醒教育金需求，展示规划方案
   准备：以子女教育切入 → 倾听 → 推荐年金险或定投方案
   注意：首次提及即可，不强求当场决策

⑤ 收尾确认（3-5分钟）
   - 确认本次沟通的行动项（哪些产品客户有意向）
   - 约定下次联系时间
   - 处理该客户关联的待办事项（如生日祝福等）
```

#### 4. 风险提示与注意事项

> **目的**：告诉客户经理什么不能做、什么要注意，避免合规风险。

```
⚠ 合规红线：
  - 不得承诺收益（不要说"保本""稳赚"）
  - 不得误导风险等级（R3产品不能对稳健型客户说"没风险"）
  - 保险产品必须说明犹豫期和退保损失
  - 基金产品必须说明"过往业绩不代表未来表现"

📌 该客户特别注意：
  - 客户历史申请过XX贷款被拒（原因：征信记录），避免主动提及信贷产品
  - 客户沟通偏好电销渠道，最佳联系时段上午9-11点
  - 上次沟通中客户表示"不喜欢太激进的产品"，推荐时注意节奏
```

#### 5. 面谈后续行动建议

> **目的**：告诉客户经理聊完之后要干什么，形成闭环。

```
✅ 面谈后建议：
  1. 录入本次沟通记录（关键内容摘要，方便下次回顾）
  2. 标记客户意向产品（用于后续精准推荐）
  3. 创建跟进任务（如"3天后联系确认理财购买意向"）
  4. 更新客户标签（如本次挖掘到的新偏好）
```

### 关键交互需求

| 诉求 | 交互要求 | 对应功能 |
|------|---------|---------|
| **一键生成作战包** | 从商机进入，点击[生成访前作战包]，AI自动整合所有数据源输出完整方案，同步创建商机待办 | 访前作战包生成 |
| **可编辑可调整** | 客户经理可以增删线索、替换推荐产品、修改话术，不是死板的报告 | 作战包编辑 |
| **线索可展开收起** | 默认只展示线索标题+一句话摘要，感兴趣的点开看完整内容 | 手风琴/折叠 |
| **话术可复制** | 客户经理可能需要复制话术到微信/短信提前发给客户 | 话术复制 |
| **产品一键对比** | 在作战包内可勾选2只产品直接对比，不用跳出去 | 内嵌产品对比 |
| **支持导出/分享** | 可导出为图片或转发到微信，方便离线查看 | 导出分享 |

## 二、面谈中（实时辅助阶段）

> **场景画像**：正坐在客户对面，或者正在电话沟通。APP是"提词器"+"搜索引擎"+"计算器"——需要秒级响应，不能翻半天找不到。

### 心智模型：**"客户问什么，我就能马上查到/答出来"**

客户经理的内心独白：
1. "客户问XX产品怎么样？" → 秒查产品详情
2. "客户犹豫了，怎么说？" → 快速获取应对话术
3. "两个产品哪个更适合他？" → 当场对比
4. "客户说了一个新需求..." → 搜索匹配产品
5. "上次聊的什么来着？" → 查历史沟通记录

### 核心使用路径（对话式为主）

```
客户提起一个话题
        ↓
自然语言输入（或语音转文字）
  "帮我查一下XX理财产品的收益"
  "XX基金和YY基金哪个好"
  "怎么跟客户说保险"
        ↓
AI秒级响应
  ├── 产品详情卡片（核心信息+四宫格）
  ├── 产品对比结论（LLM一句话总结）
  ├── 营销话术（口语化，可念出来）
  └── 兜底：查不到时给兜底文案，不卡住
        ↓
客户有新问题 → 继续对话（上下文连续，不用重新开始）
```

### 关键交互需求

| 诉求 | 交互要求 | 对应功能 |
|------|---------|---------|
| **秒查产品** | 自然语言输入，不需要填搜索表单；支持模糊匹配 | 产品洞察（自然语言查询） |
| **当场对比** | 输入两只产品名，直接给对比结论（LLM总结优先，关键差异一眼可见） | 产品对比 |
| **念得出口的话术** | 话术默认口语化，句子短，可自然读出，不是念说明书 | 话术推荐（口语化风格） |
| **上下文连续** | 聊完A产品再聊B产品，AI记得之前聊的客户是谁 | 会话管理（上下文理解） |
| **不打断对话流** | 首token响应≤8秒，加载中给骨架屏；不能白屏等待 | 性能要求 |
| **兜底不尬** | 查不到产品/客户时给出兜底文案，引导重新提问，不报错 | 兜底处理 |
| **看得见的数字** | 收益率、风险等级用可视化（色条、图表），不用纯数字 | 四宫格/风险等级可视化 |

| 要避免 | 原因 |

## 三场景对比总结

| 维度 | 见客户前 | 面谈中 | 整理工作时 |
|------|---------|--------|-----------|
| **核心动作** | 查、看、备 | 搜、比、说 | 记、理、排 |
| **时间压力** | 中等（几分钟到半小时） | 极高（秒级响应） | 低（碎片化/批量） |
| **交互方式** | 搜索+浏览（卡片为主） | 对话式（自然语言为主） | 推送+列表（待办/商机为主） |

## 交互设计指导原则

### 1. 三种模式切换自然

同一个APP要同时满足三种场景，核心是让用户**不用想"该去哪"**：

- **准备模式**：搜索客户 → 自动展开"准备视图"（画像+推荐+话术）
- **面谈模式**：打开对话 → 自动进入"对话视图"（流式秒回+卡片内嵌）
- **整理模式**：打开首页 → 自动展示"工作台视图"（待办+商机+资讯）

### 2. 信息呈现"由浅入深"

- **一层**：摘要卡片（3秒扫完） → 见客户前
- **二层**：核心详情（四宫格/对比表） → 面谈中
- **三层**：完整扩展（历史业绩/持仓/条款） → 准备时深挖

### 3. 推动下一步行动

每个页面都要回答"然后呢？"：

| 页面 | 下一步行动引导 |
|------|--------------|
| 客户画像 | → [查看推荐产品] [生成开场白] [查看待办] |
| 产品详情 | → [对比同类] [生成产品话术] [查看适合的客户] |
| 待办列表 | → [一键处理] [查看客户详情] [联系客户] |
| 话术生成 | → [切换风格] [复制] [查看推荐产品] |
